# 背词窗口、后台保存与今日计数

状态：实现与本机构建通过，生产验证待完成。

Reader 与背词关联词箭头共用 DictionaryWindow：同一单独查词内容、标题、拖动、缩放与尺寸记忆。Study 在原生顶层弹窗中使用它，避免旧自适应提示框与词典 100% 高度之间的依赖。桌面 340×560，窄屏底部窗口沿用 Reader 样式。旧空白弹窗在本机 Chrome 未稳定复现，因此不将原因推测写成已复现事实；新窗口以真实元素尺寸、可见性及点击命中验证。

FocusModality 区分指针和键盘导航。鼠标/触摸及关闭弹窗回焦点不会留下焦点框；整张卡片与答案滚动区均不画外围焦点框，空格提示仍可用。按钮、下拉列表等实际控件保留细中性键盘定位，输入框原本边界保留。个人设计库的“我的审美”与原话归档已记录这条反感项，独立本地提交 573ad32926018cb245ac5acc010baef178bb9799，未推送。

作答先按账号与不可变答案 id 写入本机 outbox，再立即跳过当前卡片。后台复用服务端 FSRS、凭据、时间门槛、幂等与奖励事务；仅确认后的快照改变完成数与奖励。下一词可立即回忆、看提示及核对，正式作答凭据等待前项确认后取得，保留服务器学习/复习阶段限制。断网或超时保留答案并自动重试；本机无法可靠写入时不推进。关闭学习界面继续保存，刷新后恢复相同答案。跨日与多标签页确认均不能因较旧快照将下一词退回或丢弃待发答案。

每步 review 不再为读取 retention 预取整份快照；Study 词条在数据库侧投影排除完整 dictionaryResult，按词缓存仍提供详情与最新例句。真实 PostgREST 别名读取已通过：3 个隔离测试词条 2410 bytes，对照完整结果 6502 bytes；单次时间不作为性能基准。

左上角显示“正在背 / 待复习 / 今日新学”。前两项是今日有效计划剩余状态，等待再次出现的词仍计正在背；今日新学复用每日数据真实首次毕业统计，不把未学完的词计进去。答案底部所有说明文字已删除，保留评级行为与右侧按钮。

本机验证：139 项架构回归、49 项词典/学习专项及 9 个发布契约通过。Chrome 四组桌面/390px、日夜、触摸与减少动态效果共有 74 个可见性/交互观测通过，包括答案与生词详情入口、反复开关、空格、Tab/Enter/Escape、Menu、下拉框和 Reader 拖动/缩放/恢复。额外延迟保存测试在词条重新生成后 35ms 显示下一词，本机 outbox 已存在，迟到确认不重置新词答案。模型与发音请求为明确替身，无供应商调用；这些不证明真实模型质量。Safari/WebKit、实体手机和用户最终观感未验证。

跨午夜未建立今日计划时，day_changed 单独触发 start 后原 id/token 重放，失败保留记录；外标签页删掉待发键前，本页先取得最新快照再放开卡片，延迟响应不使新词退回旧复习词。两个竞态经独立审计、真实 React 测试和服务端路由测试复核。39 表备份 SHA 与独立恢复通过，学习 SQL 事务回滚用例验证学习/复习/新词顺序、跨日统计、旧凭据恢复及幂等。首次恢复因 --no-privileges 略过 ACL，最后权限断言失败；确认生产两项函数授权均已撤销，并仅在隔离库复原该边界后，全套 SQL 通过，没有修改生产 ACL。
