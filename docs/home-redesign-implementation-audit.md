# 首页重设计实现审计

本文件保留技术/视觉/产品三类门槛，不能由构建替代用户验收。当前生产身份以 release-governance.md 为准，已实现的 9 月纠偏随生产源码同步；下表的旧日期证据仅说明当时验证范围。桌面词典固定限制已由 2026-09-15 的拖动/调大小决定覆盖；旧功能环已由录屏展示覆盖。

更新时间：2026-09-04

这份文件只回答一件事：已经确认的产品决定，在真实根首页与 Reader 中究竟实现到了什么程度。`已接入` 不等于视觉通过，复杂动效只有在真实浏览器关键帧对比并经用户确认后才可标为 `已验收`。

## 状态定义

- `已验收`：功能、视觉与重复使用体验都通过。
- `已接入待验收`：真实数据和真实功能已连接，但视觉或动效仍待用户确认。
- `部分接入`：只有一部分状态或表面，不能宣称完成。
- `未实现`：仍停留在决定或问卷层。
- `外部阻塞`：需要资质、账号或第三方服务，代码不能代替外部条件。

## 当前禁止宣称

- 不能把目前首页称为“最终真实稿”。
- 不能把普通 CSS 倾斜称为“完整复刻 Lusion”。
- 不能因为页面能打开、构建成功或 HTTP 200 就说视觉一致。
- 不能在 Reader 全来源恢复、登录粒子拼字的用户设备验收、反向共享转场和其他复杂视觉未完成时说两百多项问卷已经全部落地。账号自助改昵称/改密已接入，只保留真实账号回归验收。

## 待验收边界

本轮由用户指出“外刊个性化推荐/英语水平”完全漏接后，重新从当前决策总表逐项反查真实代码。确认这不是单点遗漏：个性化推荐、登录用户完整库存、Admin 首页槽位、注册第二步、账户阅读资料、游客额度文档和首页中途登录一致性此前都存在“记录过但未闭环”的情况。本轮已把这些功能接入或明确降级为待生产/待真实账号验收，不能再在报告中统称“需求已经完善”。

仍然明确未完成的已确认需求包括：Lusion 共享图像进入与反向回卡的逐帧复刻；所有 Reader 来源工作层的完整快照恢复；登录粒子拼字、手机与低动态的用户验收；手机 Menu 下滑手势与若干复杂动效；正式文案。安全找回密码的产品方向已由第 24 轮冻结，但短信发送与真实归属验证仍受企业资质阻塞，因此当前不开放。
