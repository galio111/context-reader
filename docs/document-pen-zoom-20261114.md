# 划线连续性与缩放定位

状态：独立分支候选，基于生产 20261114T163304。

PDF/Word 下划线在同一笔内按行合并相邻片段，并统一到较低基线，避免连字符/混合字高导致断口或台阶；跨页、跨行、大栏距和独立笔画不连接。兼容旧标记，渲染时修正，原始存储不改写。比例按钮先捕获当前可见页内阅读点，缩放/适宽和延迟 PDF/Word 布局后恢复该屏幕点及横向位置；短期观察布局变化，用户滚轮/触摸/非工具栏按下/导航按键立即取消保护，不争抢滚动。

验证：片段合并、旧记录、分行/分栏/分页/分笔；PDF/Word 几何缩放、重复切换、延迟布局及实际滚轮取消保护的组件回归通过。核心回归/生产构建/发布保护检查随后记录。浏览器入口仅有 MCP Apps，真实桌面/手机及双主题视觉、原件连续缩放体验仍待验收；不得以组件几何测试代替用户手感。本文修复不涉及文章结构、全文翻译/问答缓存或 Admin 发布协议。
