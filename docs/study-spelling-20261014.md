# 划词拼写与学习详情

状态：实现与本地验证完成，生产发布待验收。父版本 20261014T111000，源 9218f41dc8d34e8466d2dff72badd5a796ffbc49。

## 范围

划词语境卡支持可选拼写：原句只留一个按目标文字测量的居中输入空位，短语空格由用户输入；直接键入即可进入输入，最多 256 字符，超长输入在固定宽度内滚动。输入中的数字与空格不会触发评分或中文提示。点击任一回忆评分后显示批改；不输入则按原流程显示原句。大小写、首尾/重复空格、全角和排印撇号/连字符归一化，词间缺空格仍判错。错字/多字用红色删除线，替换正确字母紧随其后；漏字使用红色下划线补入，空格差异用 ␣ 显示；全对显示绿色及勾号。差异按编辑距离对齐，连续错误之间的孤立单字母匹配合入错段，避免零碎假匹配。拼写仅为本次卡片核对，不替代用户最终评分、不写入云端、不改变 FSRS/历史/离线事件。

划词详情在背词答案与生词本弹窗共用原句（答题时含批改）、句译、词头及发音、句中含义、基础释义、用法、搭配、新例句的单列顺序；原句仅出现一次，详情全部展开，搭配和新例句分别分区。独立词典卡保留完整词典组件。

## 验证

学习系统 73 项回归、核心 90 项回归、8 项备用模型/计费回归通过。新增第六项覆盖原句既有下划线和超长目标；6 项拼写算法测试通过。修复三个旧测试文件的类型约束后，相关 11 项测试通过。浏览器使用真实组件与受控接口检查直接输入、固定宽度、三种评分的批改、缺空格、全对、无折叠、桌面/390px/夜间/减少动态和生词本详情；截图与结果存于本机发布证据目录。

当前没有复刻不背单词未公开的内部算法。浏览器视觉自检不代表用户最终接受；真实移动设备键盘、Edge/Safari 仍未验收。
