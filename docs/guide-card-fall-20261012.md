# 游客使用说明卡牌入场

状态：实现与本机正式构建已完成；生产发布和用户视觉接受分别记录，不以代码通过代替动效接受。

## 当前行为

游客直接滚到功能展示，点击“继续探索”，真实吊牌从画面上方连续落下，挂绳展开后交给现有物理系统。入场约 1150ms，每次点击同一标签或切回该模块都重播；页面保持点击前滚动坐标。预热只准备依赖、模型与纹理，不推进入场。冷加载显示小型动态准备标记，模型可绘制后才开始完整下落，移除原来短距离淡入的空白占位卡。

入场离屏、暂停、隐藏页面和打开 Menu 时停止。恢复时丢弃停顿间隔，避免一次跳到终点。落位后仍可拖拽，移动超过 8px 并松手，保留 1100ms 摆动后进入真实 Menu 使用说明；再次选择模块取消未完成的打开计时。键盘、降低动态偏好与 WebGL 失败保留可访问的直接入口。手机沿用已确认的说明按钮，不加载隐藏 3D 吊牌。

改编继续使用 React Bits 原吊牌模型、纹理与物理关节，许可位于 `public/lanyard/LICENSE-react-bits.md`。新增的是受可见播放状态控制的垂直入场及重复播放，不是新的模型或站外参考复刻。
