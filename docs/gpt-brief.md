## 产品与架构

Context Reader 帮助中文母语用户阅读真实英文文章。阅读为主；语境解释、独立词典、翻译、生词与 Anki 支持阅读。技术为 Next.js 15、React 19、TypeScript，AI 模型配置以源码及环境覆盖为准。

- 正式地址 `https://context-reader.com`；`/` 唯一首页，`/home-v2` 保留参数永久重定向。
- `app/page.tsx` 服务端读取外刊摘要；`HomeClient` 负责文章、缓存、入口及 Reader 会话；`HomeRedesign` 是当前首页，旧 `BookHome`/`CurvedPageTurn` 仅为遗留代码。
- 腾讯云上海同机运行 Caddy、应用、PostgreSQL 17、GoTrue、PostgREST、Storage 和内部兼容网关。生产 `SUPABASE_URL` 必须是 `http://supabase-api:8000`。
- Vercel 旧完整应用和托管 Supabase 是冻结回滚参考。独立海外 fetch 服务仅处理受约束的公开网页/feed/robots，不承载账号或产品数据。
- 文章、生词、阅读状态、词典和缓存逐条写入 IndexedDB；localStorage 仅保留小型设置/身份/修复标记。旧数据先备份、校验迁移，不要求用户清站点数据。
- 登录完成与后台恢复解耦。协议 2 使用固定快照、opaque cursor、CAS、manifest 和 tombstone；只上传变化对象，恢复可续传。普通同步静默，真实本地写失败才显示备份/重试。

详情见 [architecture.md](architecture.md)、[integration-guide.md](integration-guide.md) 和 [account-usage-plan.md](account-usage-plan.md)。

## 当前产品行为

- 游客路径：Ballpit 品牌开幕 → 五模块录屏功能展示 → 精选外刊 → 正文/网址导入 → 联系反馈。登录用户新开页面进入粒子文字开场后的阅读工作台，途中登录不抢走正在阅读的位置。
- 手机保留少量背景球，明确上滑可对齐功能展示；探索仅直接打开说明，物理吊牌限桌面。普通工具层可拖动停留在 25–82dvh，低于四分之一屏或快速下甩关闭；手机划词解释也开放 AI 追问，局部滚动不串到正文。
- 首页独立查词按 2026-09-15 明确纠偏支持桌面拖动和调大小，不跨会话保存坐标；手机仍为底部面板。该决定覆盖此前固定窗口限制。
- 文章点击词或有意横划/长按短语查询；纵向移动始终是阅读滚动。IPA 和发音属于实际当前词形；流式、完成态、缓存回放保持内容一致。
- 全文翻译只由侧栏内明确动作启动；普通正文使用有界批次、逐块显示和保存。切换工具保留任务和译文滚动，重翻逐段替换而不先清旧结果。
- 保存先保住文章；首次缺有效摘要时才生成，超过 50,000 字符或失败仍可保存。保存后仅禁用的“已保存”，没有摘要重写。
- Reader 原位编辑，保留空段；撤销/重做属于阅读会话。“返回首页”回根来源快照，浏览器 Back 才逐篇恢复。长文只在视口附近挂载交互 token。
- Anki 以稳定 ContextReaderId/历史身份恢复导入回执，防止断线重试重复建卡；新卡需 US/UK 音频齐备。已有卡不被自动批量改写。
- TTS 复用私有 Storage、32 MiB/1000 条进程热缓存和 in-flight 请求；存储瞬断有限重试，写失败后台补存；重启/淘汰期间仍可能重复合成。

## 账号、额度与安全

手机号只是未验证的大陆手机号标识，不发送短信，不证明归属。注册只收昵称、手机号和密码；新密码/主动改密须 8–72 个不含空格的可打印 ASCII 字符、至少一字母和一数字。旧六位数字密码仅兼容登录。可改昵称/密码；自助找回待真实归属验证，不能通过昵称代替。

刷新 Cookie 滚动最长 400 天，但仍受上游会话、禁用、改密和撤销约束。普通退出先成功同步，使用 local scope，不退出其他独立设备会话。会话校验失败进入明确离线受限态，不能变成游客或恢复服务端权限。

- 游客上海日独立池：文章查询 10、独立词典 5、粘贴导入 2、URL 导入 2；缓存、失败、及时取消不扣。
- 注册用户的摘要和全文翻译是独立月池。新翻译任务算一次，缓存重看免费，明确重翻另算；精选预载译文首次点击算动作但模型成本为零。
- 所有登录账号均可见实际余额与北京时间重置点，独立于商业营销开关；会员耗尽不能提示“游客额度”。不完整流不能先结算成功，额度拒绝不再触发重复 fallback。
- 邀请码单次兑换 Basic/Plus/Max 有期权益；线上付款尚未接入。
- Admin 正常入口和 `/api/admin/*` 只认服务器 active admin entitlement，旧密码会话仅恢复用途。密钥不下发浏览器。
- 远程抓取保留固定 DNS、私网拦截、大小/类型限制；详细故障私存，网络/输入错误不算开发错误。
