## 当前产品骨架

- 唯一规范首页为裸域名根路由；旧 `/home-v2` 只做保留查询参数的兼容重定向，不创建 `/home-lab`。
- 游客顺序：Ballpit 品牌封面 → 精选外刊 → 自主导入 → 七卡 3D 功能环 → 联系/反馈/备案页脚。
- 登录用户顺序：短粒子拼字加载动画 → 继续阅读（有记录时）→ 更突出的导入器 → 精选外刊及可原地展开库存 → 联系反馈；不重复游客功能介绍。
- 阅读入口始终进入真实 `ReaderView`。外刊使用 Lusion 共享图像方向；导入、继续阅读和其他来源使用短而克制的普通转场。
- 桌面游客通过左上品牌胶囊悬停显示四个高频入口；登录首页和 Reader 固定显示。Reader 不显示品牌胶囊，只保留同列“返回首页”与四按钮。手机不设左栏，全部进入底部 Menu。
- 精选外刊标题区必须同时保留内容分类与“个性化推荐”。水平为高中、四级、六级、考研、雅思/托福，兴趣为八类；二者只重排默认推荐，不覆盖明确分类。
- 游客四池额度：文章查询 10、单独查词 5、正文导入 2、网址导入 2，均可由 Admin 调整；缓存命中、失败和及时取消不扣。
- 当前登录是未验证大陆手机号标识 + 昵称 + 密码，不发送短信。新注册/改密要求 8–72 位可打印字符且至少含字母和数字；旧六位数字密码继续兼容登录，直到用户主动改密。当前暂不开放找回；未来合规短信核验后重置并回登录框，由用户明确登录。昵称 + 未验证手机号不能作为所有权证明。

## 不能丢失的最新视觉纠正

- Ballpit 必须是一张覆盖真实视口的连续场，不能让内部容器边界带着球一起移动。球到真实屏幕边缘前完整可见；后续页面不能残留球。散开需要个体速度与轨迹差异，不能像整块背景平移。
- 用户报告游客与登录视角会周期性卡顿，开发模式约 6–7 秒的停顿不能被当作动效问题掩盖。只用生产构建判断基准，但用户真实设备的静置、往返滚动和连续开合仍是最终门槛。
- 第 22 轮追加纠偏明确：封面与外刊之间的约 `1.9s` 双向定点吸附必须全程同一空间速度，球体分向离场与外刊落位共用终点；只覆盖两个锚点，后续自然滚动。
- 外刊滚动显现、3D 悬停和点击必须继续对照用户提供的两段 Lusion 录屏。图片悬停不需要圆形聚光灯；文字不能因为悬停改变换行或卡片构图，只在右上出现箭头。
- 七张功能卡要形成真正无限的 3D 环：点击卡片能沿最近方向居中，拖拽有连续轨迹，快速拖拽最多跨一两张，左右都不能暴露补卡跳变；z 层级只由深度决定，侧后卡不能错误压在前卡上。
- 登录加载动画已经选定为“彩色粒子从上方掉落并拼成 `Context Reader`”。只大写 `C` 和 `R`，其余小写，两个单词保持正常空格；旧螺旋/球团/开孔全部舍弃。第 22 轮已重采样字形与粒子密度，本地生产构建中段可清楚读出词组；公网手机、低动态和用户设备仍待视觉验收。Reader 返回首页不再重播启动动画。
- Ballpit 已在透明材质、质心回归和热扰动之外增加随机软包络压力，使静置时框外只剩少量离群球，单球仍无固定落点并可响应鼠标越界。外刊图片已删除纵向铺开，改为触及视口时约半秒整体轻微放大/清晰化，离开复位、上下重播。
- Menu 未登录状态整行可直接登录，并新增“鼠标字母轨迹”和“日间 / 夜间”设置；偏好持久化并作用于游客与登录首页。查词默认小窗已经是顶部输入、下方结果。
- 中文标题不能沿用英文超大字号逻辑，不能出现莫名换行。封底、桥接句和第一屏副句都不是最终文案；第一屏副句需要同时让人理解“精选外刊资源 + 语境翻译帮助读下长文”，仍需候选稿。
- 联系区微信二维码只能由微信号文字本身触发，放在其右侧、尺寸克制且不碰分隔线。页脚包含 `蜀ICP备2026045148号-1` 与 `川公网安备 51010702044616号` 的官方查询链接。

## 尚未完成或尚未验收

以 `docs/home-redesign-implementation-audit.md` 为逐项清单。当前高风险项包括：

- Ballpit 静置/滚动性能、真实视口边界、关键帧与低性能降级；
- Lusion 首批图片进入、共享图片进入 Reader、反向回卡及重复五次节奏；
- 登录粒子拼字的用户设备关键帧、手机与低动态版本；
- 3D 功能环无限循环的操作手感、遮挡关系、手机与减少动态版本；
- Reader 各来源快照、最多五层会话栈、浏览器后退与失效外刊回退；
- 单独查词窗口吸回动效、移动端键盘和额度状态；
- 手机 Menu 下滑关闭、彩色错位层和真实设备验证；
- 合规短信验证具备资质后的自助找回实现（当前方向已冻结，尚未开放）；
- 正式中文文案、中文断行、多视口排版；
- 生产真实账号、推荐编排、个性化同步、游客四池额度和缓存退款的完整回归。

## 需求完整性核对索引

接手时不能只读本文件的摘要。必须以 `home-redesign-interview-archive` 中问题 1–292 的原始答案为证据，再逐项对照 `home-redesign-current-decisions` 和 `home-redesign-implementation-audit`。以下范围缺一项都不能宣称“需求已对齐”：

1. 产品初心、新老用户两条入口与首页顺序；
2. 裸域名规范首页、旧链接兼容与 PWA/离线/返回入口；
3. Ballpit 游客封面、滚动时间线与性能红线；登录用户独立的粒子拼字加载动画；
4. 精选外刊策展、分类、个性化水平/兴趣、登录库存与 Admin 编排；
5. Lusion 滚动显现、图片 3D、共享图像进入 Reader 与返回；
6. 正文/网址导入、URL 预览、临时阅读、额度与未来 PDF/OCR 边界；
7. Reader 左侧工具、来源快照、五层会话栈、刷新、浏览器后退和失效来源；
8. 单独查词可移动窗口、额度提示、移动端面板与位置记忆；
9. 桌面高频按钮、右上 Menu、手机底部 Menu、账户和使用说明；
10. 注册第二步、阅读资料、隐私、同步、退出、昵称/密码与暂缓短信边界；
11. 七卡无限 3D 功能环、真实小画面、拖拽/点击/层级与降级；
12. 联系反馈、微信二维码、更新记录、邮箱与两项备案；
13. 中文字号、断行、全站正式文案和不同区段的进入动作；
14. 游客四池权限、受限动作登录续接、缓存退款和 Admin 可配置；
15. 桌面、手机、键盘、低动态、低性能与重复五次的独立验收。

如果 archive 与 current decisions 冲突，只记录冲突来源并执行后者；如果 current decisions 与真实代码冲突，先在 implementation audit 标出差距，再修代码。不能靠把所有旧答案复制进提示词来制造“没有遗漏”的假象。
