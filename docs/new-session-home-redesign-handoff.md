## 当前产品骨架

- 唯一首页为 `/home-v2`，根路由跳转到它；不创建 `/home-lab`。
- 游客顺序：Ballpit 品牌封面 → 精选外刊 → 自主导入 → 七卡 3D 功能环 → 联系/反馈/备案页脚。
- 登录用户顺序：短 Ballpit 开场 → 继续阅读（有记录时）→ 更突出的导入器 → 精选外刊及可原地展开库存 → 联系反馈；不重复游客功能介绍。
- 阅读入口始终进入真实 `ReaderView`。外刊使用 Lusion 共享图像方向；导入、继续阅读和其他来源使用短而克制的普通转场。
- 桌面游客通过左上品牌胶囊悬停显示四个高频入口；登录首页和 Reader 固定显示。Reader 不显示品牌胶囊，只保留同列“返回首页”与四按钮。手机不设左栏，全部进入底部 Menu。
- 精选外刊标题区必须同时保留内容分类与“个性化推荐”。水平为高中、四级、六级、考研、雅思/托福，兴趣为八类；二者只重排默认推荐，不覆盖明确分类。
- 游客四池额度：文章查询 10、单独查词 5、正文导入 2、网址导入 2，均可由 Admin 调整；缓存命中、失败和及时取消不扣。
- 当前登录是未验证大陆手机号标识 + 昵称 + 六位数字密码，不发送短信。短信验证码和找回密码已经暂缓，不能自行恢复为本轮目标。

## 不能丢失的最新视觉纠正

- Ballpit 必须是一张覆盖真实视口的连续场，不能让内部容器边界带着球一起移动。球到真实屏幕边缘前完整可见；后续页面不能残留球。散开需要个体速度与轨迹差异，不能像整块背景平移。
- 用户报告游客与登录视角会周期性卡顿，开发模式约 6–7 秒的停顿不能被当作动效问题掩盖。只用生产构建判断基准，但用户真实设备的静置、往返滚动和连续开合仍是最终门槛。
- 第 21 轮要求试验封面与外刊之间的轻度自动吸附，同时上滑必须沿同一时间线倒放；这一点尚未最终接受，必须真实体验后保留或撤回。
- 外刊滚动显现、3D 悬停和点击必须继续对照用户提供的两段 Lusion 录屏。图片悬停不需要圆形聚光灯；文字不能因为悬停改变换行或卡片构图，只在右上出现箭头。
- 七张功能卡要形成真正无限的 3D 环：点击卡片能沿最近方向居中，拖拽有连续轨迹，快速拖拽最多跨一两张，左右都不能暴露补卡跳变；z 层级只由深度决定，侧后卡不能错误压在前卡上。
- 登录螺旋需要多层轨道可辨识，但最终不能压成扁椭圆球团再左右分拨。现有螺旋稿继续优化；“球从上方掉落拼成 Context Reader”只作为独立 wordfall 对照，用户未选择前不能替代主稿。
- 中文标题不能沿用英文超大字号逻辑，不能出现莫名换行。封底、桥接句和第一屏副句都不是最终文案；第一屏副句需要同时让人理解“精选外刊资源 + 语境翻译帮助读下长文”，仍需候选稿。
- 联系区微信二维码只能由微信号文字本身触发，放在其右侧、尺寸克制且不碰分隔线。页脚包含 `蜀ICP备2026045148号-1` 与 `川公网安备 51010702044616号` 的官方查询链接。

## 尚未完成或尚未验收

以 `docs/home-redesign-implementation-audit.md` 为逐项清单。当前高风险项包括：

- Ballpit 静置/滚动性能、真实视口边界、关键帧与低性能降级；
- Lusion 首批图片进入、共享图片进入 Reader、反向回卡及重复五次节奏；
- 登录开场最终构图和 wordfall 对照选择；
- 3D 功能环无限循环的操作手感、遮挡关系、手机与减少动态版本；
- Reader 各来源快照、最多五层会话栈、浏览器后退与失效外刊回退；
- 单独查词窗口默认位置、吸回动效、移动端键盘和额度状态；
- 手机 Menu 下滑关闭、彩色错位层和真实设备验证；
- 用户自助修改昵称和六位数字密码；
- 正式中文文案、中文断行、多视口排版；
- 生产真实账号、推荐编排、个性化同步、游客四池额度和缓存退款的完整回归。

## 新会话的第一轮工作

1. 读取公网 `/api/connectivity`，确认本文件记录的 release 没有过期。
2. 分别用游客与真实登录账号检查：首页推荐是否有数据、个性化推荐入口是否存在、登录后当前旅程是否保持、下次打开是否进入工作台。
3. 以生产构建录制三段独立短视频：Ballpit/外刊、登录开场、Lusion/功能环；不要把开发服务器周期停顿当成产品表现。
4. 对照实现审计修复 P0：空推荐、无法登录、静置卡顿、滚轮闪跳、功能入口失效。P0 未通过前不继续增加装饰动效。
5. 在不重复旧题的前提下生成第 22 轮 HTML 问卷，重点让用户对真实片段作选择；答案到达时继续代码、文档、问卷同步循环。
