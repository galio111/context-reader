# Context Reader 首页重设计当前决策总表

更新日期：2026-08-29

这份文件只保存当前有效结论，是首页重构开始前的第一读取入口。它不保存完整历史，也不把问卷草图当成最终 UI。详细交互和验收规则继续以 `docs/home-v2-implementation-contract.md` 与 `docs/lusion-recommendation-motion-spec.md` 为准。

## 如何解决冲突

1. 当前代码事实以实际代码和 `docs/architecture.md` 为准。
2. 待实现的产品目标以本文件中的“已确认”条目为准。
3. 同一问题出现多次答案时，用户最后一次明确纠偏覆盖旧答案。
4. `docs/product-journey.md` 与 `docs/home-redesign-interview-archive.md` 可以保留旧决定作为历史证据，但旧决定不能覆盖本文件。
5. 问卷里的颜色、字号、比例、圆角、草图和候选文案只有在用户明确接受视觉或文案后才能进入当前决定。
6. 标为“暂定”或“待确认”的内容不得在实现中擅自固化。

## 状态词

- **已实现：** 当前代码已经运行。
- **已确认，待实现：** 产品方向已定，但代码尚未完成。
- **暂定，待体验：** 只能通过真实原型继续判断。
- **待确认：** 仍在访谈中，不能自行选择。
- **已覆盖：** 历史决定，禁止作为当前实现依据。

## 当前实现与实施边界

- **2026-08-29 已确认，分三批实施：** 先处理严重缺陷与数据行为，再统一手机工具层，最后处理首页结构与动效。每批独立构建、发布并做公网回归，不能把三批混成一次难以定位回归的大发布。
- **第一批已确认：** URL 成功后不再显示只读预览，直接进入 Reader。常规图片本地化在短预算内完成并随正文直接显示；只有慢图片转入后台，此时文案明确说明图片正在保存、来源稳定性可能导致失败且不影响正文。词元选择必须跨块唯一；关闭查词窗口等及时取消不记故障、不扣额度、不发错误邮件。定位原句要更新保存文章的最近阅读时间和目标位置；未保存的公开推荐仍可按持久 public article 引用定位。文章语境词原则上都使用语境 Anki，单独查词继续使用基础卡。`fell` 等同形歧义同时展示词形关系与独立词头。Admin “精选并继续”切到下一篇后必须释放上一篇提交态。
- **第二批已确认：** 手机 Menu、Reader 工具、生词本等普通功能层统一为默认 `56svh` 的底部半屏，可拖到 `82svh`，每次重开恢复 `56svh`；使用“返回原文”或“返回菜单”关闭，Admin 除外。手机悬停能力必须有点按入口。
- **第三批已确认：** 手机游客封面删除所有彩球和关联屏间动效，使用普通纵向滚动；功能卡采用单张主卡加两侧露边，约 6 秒自动前进，纵向手势交给页面，明确横向手势才切卡，用户主动拖动后停止自动。桌面保留并延后逐屏揭示，功能卡慢速自动旋转且主动拖动后停止；登录粒子开场与外刊进入转场略加速，外刊图片模糊阶段缩短。
- **账号与回归已确认：** 登录浏览器会话最长 400 天，访问时滚动续期；主动退出、改密、账号停用、清 Cookie 等安全例外仍可结束会话。每次改动跑快速关键流程，每天凌晨跑完整浏览器回归，每次生产发布后跑公网烟雾；390×844 是固定手机基线。
- **2026-08-31 最新直接纠偏，覆盖旧词典窗口决定：** 首页单独查词不得继续悬空、自由拖动、缩放或记忆坐标；桌面固定停靠左侧，手机固定停靠底部，结果在内部独立滚动。手机“返回菜单”“返回生词列表”等可见按钮必须有至少 44px 命中区并高于拖动把手。摘要保存后只保留禁用的“已保存”，不提供“重写摘要”。 Reader 手机工具下边栏不锁住上方露出的正文，但面板内部开始的手势只能滚面板，空内容和滚动边缘都不得串动正文。
- **2026-08-31 性能与动效红线：** 从生词本定位或普通滚动进入长文章后不得卡死主线程。来源可用性不在 render 中同步模糊扫描全部文章，定位后不重新渲染整棵长文词元树，也不批量唤醒目标前图片；远处块保持同版式纯文本，只在视口附近挂载词元并在离开后卸载。外刊主推、普通卡和“显示更多”前最后一张都必须执行同一清晰放大入场；先绘制复位关键帧再观察，避免首帧已可见时漏播。

- **已上线：** 裸域名 `https://context-reader.com` 是唯一规范首页，地址栏不再保留 `/home-v2`。根路由直接服务 `HomeRedesign` 与 SSR 外刊；旧 `/home-v2` 只作为兼容入口永久跳回根首页并保留查询参数。当前生产为 `20260829T110400`（父版本 `20260828T164504`，源码 `ec2af7622b92ad770887f1f3d89496ac04007755`），已经包含 2026-08-29 第一批严重缺陷与数据行为修复；第二、三批仍是已确认待实现。所有站内返回首页、退出登录、PWA 启动和离线回退都指向根首页。
- **已实现，待视觉验收：** 当前工作区已移除真实首页的书本式翻页和滚轮翻页，接入 Ballpit 品牌封面、真实 SSR 外刊、自主导入、功能介绍与联系区；这些只是持续迭代中的真实切片，不等于 Lusion、球幕和全站视觉已经通过。
- **已实现，待用户设备复验：** 用户在第 21 轮再次指出游客与登录视角均明显卡顿，游客更严重，并具体观察到静置约 `6–7s` 就停顿一下。现场诊断发现高刷新率屏幕使 Ballpit 跟随约 `150–165Hz` 持续更新，同时鼠标字母画布在无交互时仍持续申请动画帧；游客首屏会叠加两套全屏画布。当前本地实现已把 Ballpit 更新上限压到高刷屏约 `82Hz`、普通屏保持原生约 `60Hz`，降低球体几何/像素预算与数量，缓存指针边界，并把字母场改为只在初绘、指针移动和粒子存续时运行。进一步对照确认 3000 开发模式存在约 `519–620ms` 的周期性停顿，而相同页面的 3100 生产构建 15 秒内最差帧间隔约 `16.8–25.4ms`；后续复杂动效只在生产构建验收。该证据仍不能替代用户在原设备确认 3100 体感。
- **已确认，待实现：** 不创建 `/home-lab` 或断开真实功能的假首页。第一版可评审切片就必须连接服务端推荐、`HomeClient`、账户/Menu 和真实 `ReaderView`。
- **已确认，待实现：** 技术通过、视觉还原、重复使用体验是三道独立验收；只有用户明确接受，复杂动效才能成为受保护行为。

## 产品定位与首页顺序

- **已确认：** 产品初心是让用户遇到长篇或难读英文时，可以粘贴正文或输入文章网址，迅速进入适合阅读的正文，并在原文语境中理解词语。
- **已确认：** 语境解释与语境翻译仍是核心能力；精选外刊与自主导入是并重的两条入口。
- **已确认：** 新用户与未登录用户的首页顺序为：品牌封面 → 精选外刊 → 自主导入 → 功能介绍 → 联系与意见反馈。
- **已确认，覆盖第 18、19 轮：** 登录用户首屏把继续阅读与自主导入放在同一居中工作台：继续阅读进一步缩小，导入器成为更突出的主模块；不显示“接着上次停下的地方”“带一篇你的文章来”等可由界面直接理解的说明。最近文章暂时移除，只保留“我的文章”入口。随后进入精选外刊与可展开库存，最后保留联系与意见反馈。
- **已确认：** 有阅读记录时，“继续上次阅读”是第一主动作，自主导入紧随其后；无阅读记录时隐藏空的继续阅读，把自主导入和精选外刊前置。
- **已确认，覆盖单一编辑式方向：** 继续阅读默认使用克制封面参与版本，让文章更快被辨认；当文章没有封面图时自动回退到编辑式文字、进度和极短预览。模块已有悬停抬升、边界和箭头反馈且方向获接受；不附加最近文章列表，完整历史从“我的文章”进入。
- **已确认，按最新工作台纠偏：** 手机保持“继续阅读 → 自主导入 → 外刊”的信息顺序，不重复最近文章列表，也不要求继续阅读与导入器强行塞进同一屏；完整历史仍从“我的文章”进入，正常纵向滚动优先。
- **已确认：** 完全没有阅读记录的登录用户不显示空继续阅读或空最近文章；导入器成为第一主景，精选外刊紧随其后。

## 首页后半程屏间连续性

- **已确认，覆盖范围仅限封面之后：** 外刊、导入、功能卡片与联系区都使用浏览器自然滚动；动效只读取区段进入与离开的进度，不吸附、不分页、不接管持续滚轮。封面与外刊之间是唯一例外，按下文使用一次可逆的定点吸附，二者不是同一范围。
- **已确认，待实现/验收：** 外刊最后一行正常滚出，同一浅色纸面缓慢换色，以桥接句进入个人阅读现场；不使用硬切背景或另一块突然盖上的整屏容器。
- **已确认，待实现/验收：** 导入器进入视口时按“模式标签 → 输入面 → 动作”分层落位；离开时继续与功能介绍形成视觉接力。第 19 轮已否定三张超大功能章节作为当前方向。
- **已确认方向，待视觉验收：** 功能能力改为七个较大的功能卡围成立体环形。前方同时可辨识约三张，其余形成空间背景；鼠标拖拽、触摸滑动、左右按钮和点击卡片都能旋转到目标卡，快速拖动最多跨一至两张并保留连续轨迹，左右无限循环且不显示 `1/2/3/4` 序号。每张卡使用真实小画面、二至四字名称和一句短说明，并有明确悬停反馈。环形方向已接受，但卡片最终尺寸、真实画面、透视和手机降级仍须真实验收。
- **已确认，待实现/验收：** 手机保留相同顺序和关键接力，减少重叠和运动距离并允许自然滚过；系统减少动态效果时保留色场和布局接续，取消覆盖、视差和大位移。

## 登录状态与当前旅程连续性

- **已实现，待完整旅程复验：** 首页首次完成账号状态解析后锁定本次旅程外壳。游客在当前首页中途登录只更新身份、权限和同步，不切换到登录工作台；下次全新打开才默认进入登录工作台。Reader 中途登录与全部来源返回仍按下条继续复验。
- **已确认，待实现：** 游客从某篇外刊进入 Reader、在 Reader 中因受限能力完成登录后，继续停留在当前文章；返回时至少必须恢复登录前的游客外刊界面、分类和滚动位置。此前“Reader 返回一律直达 Ballpit 封面”的规则不再足以覆盖该场景，完整返回矩阵需后续单独收口。
- **已实现，待浏览器登录实测：** 游客在首页 Menu 中登录后仍停留在当前游客首页和原位置。本次挂载不因身份变化自动换首页；下次全新打开网站时，再按登录身份进入工作台。
- **已实现：** 账号与数据页和 Menu 账户内容保留退出登录；退出后结束账号工作层并进入游客首页。
- **已覆盖：** 游客能力、四池额度、受限动作和登录续接已经在“游客权限、额度与登录续接”一节收口；此处不再作为待访谈项。剩余待定只包括提示的最终视觉与文案。

## 审美与表达基线

- **已确认：** 用户喜欢现有五彩 Ballpit 球体碰撞，把它视为封面或品牌 IP；喜欢鼠标移动时字母飘出的效果；喜欢现有封面按钮的悬停反馈。
- **已确认：** 开发者的话真诚，适合重构后进入使用说明，而不是丢失或继续作为主页长篇介绍。
- **已确认：** 用户喜欢 I Read World 的简洁、清晰和外刊内容秩序，但明确不要求模仿其视觉；Context Reader 必须保留自己的品牌第一印象。
- **已确认：** Lusion 录屏定义精选外刊的悬停 3D、滚动出现和点击共享图片转场目标；复刻的是动效语言，不是其品牌、内容或私有源码。
- **已确认：** 首页可以表现力强，但不能“已经花哨到影响使用，却仍静态、平庸或不惊艳”。强动效要集中在少数关键时刻，Reader 保持安静。
- **已确认：** Menu、浮层和悬停内容不能再用透明背景牺牲文字可读性；可读性不是后续美化项。
- **已确认：** 文案不能直白粗糙，也不能为了美感变得看不懂。除已确认主句外，候选文案必须继续由用户把关。
- **已确认：** 用户不接受“AI 做完一整套再开盲盒式调 UI”。复杂界面和动效必须小切片、真实功能接线、浏览器自检和用户逐段验收。

## 封面与第一屏

- **已确认，待实现：** 保留现有 Ballpit 五彩球体自由碰撞效果，把它作为品牌/IP 门面；不再暗示实体书。
- **最新实现，待用户设备验收：** 宏观目标区仍对应封面右侧红框，单球没有固定归位点。第 25 轮在用户确认回流倾向仍不明显后，把质心与软统计包络回流再次加倍到最初实现的约四倍，同时保留随机热扰动；目标是静置时框外通常只剩少数离群球，鼠标碰撞后仍可短时把任意球撞出区域。
- **已确认，待实现：** 新用户封面约占一屏的大部分高度，精选外刊从底部露出一线。
- **已确认，待实现：** 静态构图是有留白的品牌门面、无明显边框的中心球场和偏左克制文案；不是全屏球幕，也不是常规左右分栏 Hero。
- **已确认：** 第一屏主句是“在语境里，读懂英文。”，信息密度为主句、一句克制说明和一个进入动作。
- **待确认：** 副文案、动作名称、字宽、断行以及封面底色。第 20 轮三句副文案全部被否决，而且用户尚不清楚副句会出现在哪个具体位置；下一轮必须先用真实位置或示意图说明，再讨论文字，不能脱离构图继续给句子。

## Ballpit 到精选外刊的转场

- **已确认，待实现：** 封面等待时，球体一直自由漂移和碰撞。
- **最新确认，本地已精修待用户设备验收：** 游客在封面向下滚动时吸附到外刊起点，向上沿同一路径吸回封面；点击“精选外刊”复用同一路径。完整行程仍约 `1.9s`，但页面位移改为全程同一空间速度，不能再用明显加速—减速曲线。球体从当前位置同步向两侧散开，外刊抵达锚点时球体刚好完成离场。吸附只存在于这两个相邻锚点。
- **最新确认，本地已精修待视觉验收：** 球材质在桌面和手机都略微透明。此前只纠正群体质心，实际仍有太多球长期停在目标框外，用户明确不通过。当前算法改为“质心回归 + 软统计包络 + 个体热扰动”：目标仍是封面右侧宽区域且没有单球固定落点；只有接近或越出群体包络的球受到带独立游走目标与切向扰动的回流压力，鼠标碰撞后可暂时越界，但静置时框外应只剩少量随机离群球。
- **已确认，待实现：** 转场必须从触发瞬间每颗球的真实位置和速度继续，不能先换球阵、重置坐标、切画布或切到预设场景。
- **已确认，本地精修待验收：** 转场使用同一个覆盖视口的 Ballpit 画布，不允许球群连同旧容器边界一起移动。球在到达真实视口边缘前必须完整可见，可以飞越下一屏的“精选外刊”文字；中途停留不得闪现另一颗球、切画布或重新随机。球体先让出中央通道，接近终点才完全离开；外刊列表同时从下方连续上移并承接 Lusion 式速度形变。
- **已确认，本地已接入待验收：** 列表完全到位的同一终点，球体画布必须彻底隐藏，后续页面边缘不残留球；反向滚动到转场时再恢复同一画布。资源是否在终点直接卸载仍需与可逆滚动和重建闪烁共同评估。
- **已确认的性能红线：** 普通滚轮、任意中途停留和封面静置都不能出现闪屏、跳到更下方滚动位置或可感知卡顿。实现必须避免每帧布局测量和重复初始化 WebGL；低性能设备的实际降级阈值仍需下一轮真实体验确认。构建通过或高性能开发机流畅不能替代该验收。
- **已确认：** 封面、外刊、导入、功能环和封底保留不同的低饱和色场，但相邻边缘必须以长距离渐变和共享色彩线索柔和融合，不能出现整屏硬切或明显色带。
- **已确认，待实现：** 转场未结束时明确向上滚动，从当前进度自然反向；完成后轻微反向滚动不重播开场。
