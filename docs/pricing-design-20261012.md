# 套餐页设计

状态：已生产接受 `20261012T201305`，父版 `20261012T161101`，源码 `491f29761540d42314e6cc435b28788b3c04c0b5`。公开身份和服务器接受状态一致（`mainland_internal`）。用户最终审美确认与真实手机验收仍待进行。

## 设计与来源

以本轮实际浏览的 Context Reader 公开首页和原 `/pricing` 为视觉基准。沿用主站浅灰蓝 `#f5f8f9`、深色文字 `#173443`、Arial/中文系统字体、左上品牌胶囊和站点蓝色操作。用户个人设计库当前明确要求清楚、短文案、统一控件，玻璃限于工具层；本次仅返回控件使用轻微背景模糊。没有把设计库未确认的材质候选当成已接受偏好，也没有移植第三方代码或引入依赖。

付费 Basic / Plus / Max 三栏对比，免费账号独立横排保留登录/返回阅读入口。中档保留原有轻强调，不添加未经证实的“最受欢迎”标签。年付总额、月均额与节省金额由公开目录计算，每月点数和当前套餐均来自原服务。320–700px 重排为单列，卡片内价格与额度并列，使用真实中文内容核验。

月年切换的白色滑块为原创 CSS 状态过渡（220ms），按钮悬停箭头为 180ms；不拦截滚动、不等待动画完成。减少动态时禁用过渡，费用区滚动立即完成。没有宣称这些效果已获用户最终认可。

## 业务与交互

`BillingPage` 同时服务 `/pricing` 和账户内 `BillingDialog`。原报价、抵扣、年付补充点数、扫码、订单状态及轮询接口保持。未开放支付时按钮为查看费用，确认支付仍禁用。普通免费入口只进入登录或返回阅读，不变更已有套餐。年付不是一次发放全年点数。

常用点数费用默认展开，周期和升级说明按需展开；原权益抵扣公式、失败不扣点、首次领取摘要/译文扣点等规则保留。读取报价和创建订单有可见加载反馈；读取报价期间禁用付款周期切换，避免在途报价与可见周期不一致。报价/订单出现后聚焦费用区；关闭弹窗仍恢复原入口焦点，Escape 不关闭下层账号界面。

## 验证

- 本机 Chromium：月年价格、年付节省金额、1024/768/700/390/320px 无横向溢出、键盘切换、未登录打开登录、已登录报价、禁用支付、反复切换清除旧报价、失败后重试、减少动态、账号内打开/返回/Escape/恢复焦点全部通过，零页面错误。接口隔离 fixture 只用于本机测试，不能替代真实公网接受。
- 核心 90/90、架构 139/139、计费/独立提供商回退 4/4、9 项发布契约、出口审计及生产构建通过。
- 构建前发现既有兼容性测试的历史译文 fixture 包含 `type`，但返回类型只声明 `ArticleTranslationItem`。仅补充交叉类型说明，fixture 字节和所有行为断言不变，未修改运行时缓存或译文协议。
- 实际微信收款仍未开放；不以二维码或 fixture 验证声称已完成真实支付。真实设备、其他浏览器及用户最终视觉接受仍开放。
