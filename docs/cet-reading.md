扫描文本清理页脚、跨栏结构框图与译文混入；中文词义注释补充中文识别并校正，百分号回看原页，答案 I/D、J 等易混字母结合选项和定位段落校对。部分解析按来源论证整理为简洁中文，不将整理文字冒称原件逐字转录。

每份材料保留试题、答案原链接，`data/cet/source-manifest.json` 记录来源版本和 SHA-256。扫描版由两种识别结果辅助校对，对漏掉的关键答案回看原 PDF；题库是来源参考答案，不冒称官方发布。只导入阅读，不带听力、写作、翻译试题。原始 PDF、识别模型和中间图像不进入 Git、公开静态资源或生产包。

## 新版学习流程（本分支已实现，生产验收待补）

- 仅四级/六级，支持按卷与按题型；游客每级展示六套或六篇。会员目录按十二套分页、支持年份筛选；最近练习独立滚动、分批加载。
- 打开材料先选择目标，不自动创建答卷。已有记录明确提供继续或查看结果；开始新练习/自测创建独立 ID，不复制旧答案。
- 阅读练习允许查词与翻译，选择、改选和清空只修改草稿，三种题型统一按篇提交。未答确认可取消；本机持久化成功后才显示解析。每篇结果冻结，下一篇仍可答，整卷显示完成篇数。
- 阅读套卷自测/单篇自测在开始时固定范围和预算。进行中关闭查词、翻译、保存、生词、提前查看答案和答案外链；提交后恢复精读。结束并精读保留未完成结束快照，不改活动目标。
- 选词填空在原文空格内下拉选择；解析位于正文下方。题型切换保持当前滚动坐标，上一篇/下一篇回到顶部，底部导航固定。
- 练习只累计当前未提交篇章的可见学习用时；已提交篇的复盘不增加原用时。新版自测默认整卷 40 分钟、单篇 10 分钟，开始前可设 1–180 分钟，开始即倒计时。隐藏、刷新和浏览器后退继续预算；应用内保存离开明确暂停并永久标记中断，暂停隐藏正文。旧版自测保留手动计时，不归零、不转换成新版连续自测。
- 整卷按一条尝试记录，单篇按独立尝试记录；重做创建新记录。保存文章调用现有保存链路，只保存当前阅读正文，保留已保存禁用状态。
- 手机显示完整真题顶部工具和选择/历史/重做入口，弹层头部关闭按钮固定、支持 Escape 与背景关闭。全文翻译仍须点击启动，每篇阅读完整地进入同一个有界多段批次，携带全篇上下文；不是每段单独请求模型。

## 性能与同步边界

`/api/cet` 首次只返回目录元数据，单卷正文仅在进入时读取（本轮游客目录约 7.9 KB，扩库后最大单卷原始 JSON 76,278 字节，53 套目录文件约 147 KB，仅服务器使用）；数据文件在服务器私有目录，由 Next standalone tracing 打包，不进入首页 JS。真题组件动态加载，首页原有 SSR 外刊、媒体可见性和延后加载策略保留。单卷四部分只挂载当前一篇，离视口的查词节点退回纯文本；秒表自己的数字独立更新，不每秒重绘正文。目录/历史逐页或逐批展示，避免未来十年资源一次渲染。未来如超出当前目录规模，应迁移目录索引与服务端查询，不把整库 JSON 改为客户端 import。

新版管理键为 `context-reader:cet-activities:v2`、`context-reader:cet-finalizations:v2`、`context-reader:cet-exposures:v2`。对应 protocol-2 preferences 前缀为 `cet-activity:v2:`、`cet-finalization:v2:`、`cet-exposure:v2:`，复用原 CAS、manifest、游标、IndexedDB、归档与账号恢复。首登只认领游客记录；跨账号归档包含三种对象。异步开始/提交/离开返回前重新检查 owner。

草稿逐题使用时间、事件 ID 与稳定平局裁定，支持清空；目标和范围不可变。提交包先保存独立快照再写活动，恢复时可重建终态；快照包含原答案、题目选项、参考答案解析、版本和计分指标，迟到草稿不会改成绩。双端不同提交保留两份快照，结果页分别查看并排除默认统计。未使用服务器裁定先后，因此不把墙钟先后当作唯一主提交依据。旧版客户端不认识新前缀，但原协议只从明确 tombstone 删除对象，不从缺失项推断删除；回滚后新版数据仍保留，旧界面暂不展示。

构建脚本以规范化完整正文计算 SHA-256 材料 ID，以题组内容计算独立题组 ID。只对完全相同材料共享既往接触，不靠标题猜测。正文阅读、作答、辅助成功展示、答案展示分别记原发生时间。提交后的精读不追溯污染自测；迟到的作答期间辅助/答案事件会补充条件标记并改变 `cetEligibility`，不改数值快照。标签仅说明本站已知条件，无法证明站外首次接触或监考独立性。

旧 `cet-progress:v1`/`cet-attempt:` 原始记录保留。打开旧历史时用 `legacy:<id>` 幂等适配，已提交记录只读；旧 study 已反馈题保留锁定，旧 exam 已提前查看的事实保留。旧答案无法保证就是历史提交瞬间的值，统一标记条件不完整。旧空白记录保留可见，不计入新版成绩；损坏原始存储不清除。新旧客户端写入不同命名空间，旧客户端不能覆写新版快照。

## 扩库流程

1. 核对同一试卷有配套阅读答案，先排除缺答案资源，再写入来源清单。`scripts/download-cet-sources.py --output <站点外目录>` 仅下载当前已审核题库对应的一对试题/答案，校验 SHA-256。
2. 在站外解析 PDF；对扫描件核对段落、题号、选项与答案，不能把识别成功等同于内容准确。必要时回看原页。
3. 写入单卷 `data/cet/cet*.json`，每卷题号 26–55、四个阅读部分、完整答案与解析。`scripts/import-cet-explanations.py --ocr-dir <目录>` 可辅助现有四级材料，但结果必须人工复核。
4. 运行 `python scripts/build-cet-catalog.py`，生成不含正文、选项和答案的目录。运行 CET 回归、既有阅读核心测试与正式构建；按生产治理流程累积发布。
