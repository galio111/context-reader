所有采用文件固定来源commit并校验Git blob或LFS SHA256。录音本地识别只用于对应核验；网站展示原文和答案取自文件，未用识别结果生成原文或答案。新增每套25题、8组四级/7组六级须完整；所有组匹配均值≥92、最低≥80（此为对齐分数，不是准确率）。部分打印答案、货币符号另作来源复核。

六级2023年12月来源的两套音频文件名互换：原0609x试卷核对25题身份，逐组录音匹配后纠正引用；第1套第24题的£25,000按原PDF第3页校正。其他年份/年级错标且未能交叉核实的录音排除。第三套只有共用说明但题序不明的材料不复制。

新增逐题处展示真实参考答案与下方完整原文，原始资料保留来源入口，本批未统一整理逐题详细解析；没有以机器生成的解释冒充源解析。原19套既有详细解析内容保留，仅来源确认的水印/页脚移除。

二次原卷排版核对修复497处选项空格/标点，逐处断言全部字母和数字顺序、大小写完全相同；另13处OCR按原生Word段落或实际PDF图片复核，一段百分比的TeX包裹符号转成可读文本。证据分别为`final-option-formatting-proof.json`和`targeted-original-corrections.json`。发现不同来源的选项顺序、干扰项版本或原PDF文本层错误时，不以另一份答案表覆盖；题目顺序与其对应答案仍成对保存，既有提交快照不改。

## 使用与性能

音频保持原始MP3/M4A，不转码。内容SHA命名，静态Range/immutable缓存；单卷加载原文，首页/目录仅题组身份与题号，播放前不请求录音。练习暂停/拖动、自测连续播放、提交后原文查词与原活动/协议2同步沿用现实现。音频来源进入提交快照，之后来源修改不能改写历史。
