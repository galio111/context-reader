# 首页资源标题上浮修订

## 当前行为与决定

用户在 2026-10-02 明确否定横向揭开的观感，要求改回上浮，并将未选标题在原有 3px 差值上再缩小 3px。当前游客与登录首页共用 6px 差值和浅色状态。新进入默认外刊，Reader 返回恢复分类；游客两级各 12 条、无初始真题加载文字、同一收尾桥接句及原动效继续保留。

展示退场与标题进入使用自然滚动，无新吸附或强制等待。展示底边从视口 82% 移到 38% 时用 smoothstep 渐隐，最多轻缩 2.5%；资源标题的静止顶边进入 82% 时开始整体上浮淡入，到 54% 稳定。上浮幅度为 clamp(18px, 2.8vh, 28px)，标题与斜线一起移动，无横向裁切。副标签最多上移 14px，目录控件同步淡入。几何只在尺寸变化时测量，并用 h2.offsetTop 避免动画位移反馈；仅附近滚动申请帧。键盘焦点立即显示控件，低动态/关闭动效直接显示，固定 body 的弹层保持当前进度。

10-01 横向揭开与 3px 差值属于被用户纠正的历史方案，不能恢复为当前方向。原封面图片动效与清晰度保持既有契约。
