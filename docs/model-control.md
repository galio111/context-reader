## 使用方式

后台新增“模型与调用”：顶部列出 DeepSeek Flash、DeepSeek Pro、智谱 GLM-4.5-Air、小米 MiMo V2.6 Flash 和仅供判断的 Jev。下方可保存划词解释、单独查词、全文翻译、文章摘要、句子追问、分类难度、自动精选及独立图片检查的主备模型。

“用户与额度 → 套餐额度”每个套餐增加主备模型，可选择继承功能默认。服务端已验证的套餐优先于文字功能默认；客户端传入的套餐或模型不能绕过此规则。自动精选不使用用户套餐覆盖。新请求生效，已开始的流不更换模型，已有缓存继续复用。禁用的 OCR 不是当前产品能力，不新增入口。

模型配置位于私有 `account_settings.ai_model_routes_v1`。API `/api/admin/models` 每次验证 Admin 权限，修改还验证同源、请求大小、模型能力和密钥存在性；保存与自动精选共用租约，抓取中返回冲突而非中途修改审核策略。密钥仅来自服务端环境，浏览器不会收到。

支持上述已接入模型的选择，不承诺未知新供应商自动兼容。新增模型须更新 `modelCatalog.ts`、供应商适配和费用表并验证能力；不会把任意模型名称自动发送到错误的厂商。

## 状态含义

- 绿色：十分钟内有成功调用或主动测试，不代表下一次必然成功。
- 红色：缺密钥、余额明确不足，或近期调用/鉴权失败、限流。
- 黄色：尚未测试或观测已过期；不把未知当作正常。
- DeepSeek 通过官方 `/user/balance` 显示账号余额，两种模型共享这份余额。其余三家暂未确认公开余额接口，显示未知并使用官方控制台。
- 不推测服务商实时排队量；“繁忙”仅依据 429 等实际返回。
- “测试连接”明确标注少量付费，一次请求、25 秒上限、5 秒操作间隔，并记入系统调用记录。不会定时后台烧钱探测。

## 自动精选和 Jev

目标约 60，至少 55，四个板块分别 13–17，因此总上限实际为 68。达到 60 且分布达标即可停；某类不足时可继续补至 68。已满类别的合格候选保留，不删除、不改标签凑数。难度仍相对均衡。CNY 1.50 硬上限包含所有供应商、失败与未知预留；时间/预算/供给不足会报告未达标。

默认 Flash 综合审核、无自动精选备用，Jev 默认关闭。选择不支持图片的主模型或备用模型会拆成文字与图片两次审核；图片路由只能选择支持图片的模型。文字服务故障仅允许一次已配置备用，所有实际尝试分别预留并记账。

Jev 使用官方 `POST https://api.typesafe.ai/v1/systemone` 和 `jev-latest`，问题采用 `noul`。单次判断正文缺失、非正文杂质、媒体依赖、推广性质。缺陷概率 ≤0.10 / ≥0.90 才独立采用；不确定字段交主模型，已明确字段从主模型 JSON 要求中移除。明确缺陷先拦截，节省后续生成调用。图文匹配、摘要与复杂难度仍由生成模型承担。API 失败允许主模型接手；费用边界错误不允许继续。阈值不是已测准确率，不能把厂商概率当作本站人工标注结果。

Jev 增加了独立请求；通过文章仍需要生成摘要和图片检查，所以不能承诺开启后一律省钱。它主要在提前拒绝问题内容时节省后续调用，需要以真实账本衡量收益。

## 密钥设置及官方入口

运行 `scripts/configure-model-keys.cmd`，或 PowerShell 调用 `.ps1 -ProjectRoot <项目目录>`。输入隐藏、留空保留原值，只写 `.env.local`，不自动部署、不打印密钥、不使用命令行传密钥。确认私有文件不入 Git。正式服务器使用相同变量：`MIMO_API_KEY`、`TYPESAFE_API_KEY`。

- 小米：[控制台](https://platform.xiaomimimo.com/)，创建普通按量 API Key，在账户余额充值，不购买不适用于该调用方式的 Token Plan。[充值说明](https://mimo.mi.com/docs/en-US/quick-start/faq/payment)。模型 `mimo-v2.6-flash`，地址 `https://api.xiaomimimo.com/v1/chat/completions`；禁用思考、限制输出，使用 `max_completion_tokens`。[API 文档](https://mimo.mi.com/docs/en-US/api/chat/openai-api)。国内每百万 token 缓存命中 ¥0.02、输入未命中 ¥1、输出 ¥2。[定价](https://mimo.mi.com/docs/en-US/price/pay-as-you-go)。
- Jev：[TypeSafe 官方控制台](https://console.typesafe.ai/)，Key 和充值按官方控制台流程；不要将相似名称的售卖站当作官方。[直连说明](https://docs.typesafe.ai/introduction/quickstart)。官网公开输入 $42/十亿 token（$0.042/百万），账本按已公开输入价估算；输出暂按零计价，这是待核对的计费假设，尚未获得直连接口账单验证。启用前必须核对实际计费。
