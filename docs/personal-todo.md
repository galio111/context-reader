# 私人待办

站主把 `/todo` 加入书签即可直接进入。首页 Menu 只为服务端核实的站主显示「私人待办」。未登录时入口使用已有手机号和密码。个人数据保存在大陆主站数据库的独立工作区，浏览器的公共离线缓存排除这个页面和接口。

## 使用

随手记支持回车整理、Shift + Enter 换行。批量事项先预览再保存；日期含糊时可以点今天、本周、具体日期或无时间限制。用户可选时间、分类、优先级、提前开工天数以及每日漏做后的处理规则。清单行支持原位编辑。全部待办按分类显示。同一分类默认按截止日期和时间排列，未定日期放在末尾。长按事项正文并拖到另一项的上半部或下半部可调整顺序；键盘可聚焦事项后按 Alt + 上下箭头。手动顺序随账号保存，新事项排在手动清单之后。分类旁可恢复按截止时间排序。分类名旁的加号可直接录入该类别的待办，空分类也可以添加第一项。点击月历中的一天后，日期标题旁的加号可直接录入当天事项，确认时可调整日期和时间。日期和分类旁的加号也能以输入的名称新建固定事件。清单、录入预览和月历会标出明天、后天和大后天。

今天显示临期、已到开工日、每日任务，以及明日全部未完成的一次性待办。完成动作在原位画勾并收进「今日已完成」，可撤销和回看。没有完成日期的旧备忘录记录单独归档。每日任务只出现在今天的待办清单中，完成记录仍可在历史中回看。月历直接列出一次性事项的标题，未完成且已指定高优先级的事项排在当天前面，以较深底色标识。日期右侧标出明天、后天或大后天。每格列出当天所有事项的名称，有具体时间时同时显示；较长标题可在当天明细中完整查看。勾选后，事项从月历、计数和悬停预览移除，恢复后重新显示。

月历的「＋ 事件」或日期加号下的「记事件」支持单次事件、某周待定及固定事件。某周待定按周一至周日显示，标注具体日期待定。明天的日程会在今天页面单列。录入课表、组会时可选择每周的多个星期几或每月几号，也可设置起止日期和时间。短月份跳过不存在的日期。今日和选中日期显示当天固定事件，编辑或删除针对整组。

设置可更换紧急色。到期开工、未来 24 小时内到期、逾期或高优先级的事项自动标色。录入或编辑时可给单项选色，紧急原因仍显示在清单行。设置支持新增分类、改名和删除。改名会同步更新待办和完成记录中的分类名。删除后保存，原待办移至未分类，历史记录保留完成时的分类。也可以调整每日任务默认行为、历史参考和邮件提醒。AI 处理当次输入，启用历史参考时传入分类与聚合统计；近期相似事项也可在前端提供类别建议。日期和开工提前量由用户确认。邮件默认关闭；启用后，具体时间的事项按提前分钟数提醒，全天事项按设置的当日时刻提醒。每日任务不发邮件。邮件列出标题和时间，未定日期的一次性事项不触发。

## 运行与验证

- `GET/HEAD/PUT /api/todo` 复核站主身份。整份清单按修订号比较更新，跨设备写入冲突后重新读取并应用本次操作。
- `POST /api/todo/parse` 使用服务器 DeepSeek 配置，异常时保留可编辑的本地候选。浏览器没有 API 密钥。
- 数据库迁移位于 `ops/mainland/migrate-private-todo.sql` 和 `docs/private-todo-reminders.sql`。首次绑定在同一个 psql 会话设置已核实的所有者标识，数据库拒绝替换现有绑定。
- 主机每分钟运行 `context-reader-todo-reminders.timer`，先确认工作区当前授权和提醒状态，再按任务实例领取发送。SMTP 交付结果不确定时抑制重复，已完成实例跳过。可用 `run-todo-reminders.py --env <runtime-env> --check` 做非投递检查。
- 测试覆盖站主边界、私有缓存、修订冲突、日期解析、SMTP 去重及每日任务免提醒。浏览器验收分别检查桌面、手机视口和真实账号，不以未登录页代替完整操作验收。
