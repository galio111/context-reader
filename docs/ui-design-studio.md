# 设计工作台

已上线：后台 [设计工作台](https://context-reader.com/admin/ui-studio)，仅开发者账号可进入。

## 怎么使用

1. 登录开发者账号，进入后台的「设计工作台」。
2. 左侧选页面，在中间的真实页面中点选一个元素。需要打开菜单、答题或切换面板时，选「正常操作」；再切回「选择组件」。选择模式只选取，不执行业务点击。
3. 右侧改颜色、字体、尺寸，或拖动元素。按钮支持个人库的小样、材质及悬停效果，小样可以直接操作。
4. 用「对比原版」、撤销、重做检查整体效果。电脑与手机的位置分别保存。
5. 「保存方案」只存草稿；「应用到全站」才改变正式网站。「恢复上次上线」可回到前一个正式方案，草稿仍保留。

「效果清单」按首页、阅读、背词、词典、菜单、真题、账号、套餐、说明、后台和通用效果归类。可搜索、查看触发方式和代码位置，自动打开对应页面及其设置、数据、菜单或弹窗，并滚到目标。目标尚未显示时会说明，不能用首页冒充定位成功。复杂效果与旧版记录明确标识；没有定位标记的记录只打开所属页面。

## 本轮覆盖

清单有 **317 个界面项目、51 项动效，共 368 条**，其中 **273 项可调整外观**。这些是实际界面目标，不是 368 个任意替换的组件。另附源文件和 JSX 节点索引，便于后续逐项接入。基线是生产源码 `b590ed3`，本轮新增九个背词操作按钮的稳定标记。源码索引不等同于所有状态都已通过浏览器视觉验收。

- 实际页面预览：登录首页、游客首页、阅读、背词、词典、四/六级、账号、套餐、使用说明和后台。
- 个人组件库：19 款可在现有按钮上增强的按钮/悬停样式，9 种材质加原样；保留原本的文字、事件和禁用状态。
- 外观：颜色、中文/英文字体组合、字号、圆角、内边距、间距、宽度等，按目标提供可用选项。
- 位置：在原布局内相对移动，支持拖动、方向键微调、Shift 加速及手机独立位置。保留原占位，不是跨容器的自由排版；排列顺序只对 flex/grid 同级项有效。
- 动效：可向适合的容器/文字加入淡入、浮出、展开并重播；原站的 GSAP、物理球、吊牌、手势抽屉等独立复杂动效已盘点，但尚不能用通用编辑器任意替换或改参数。

完整个人库随站保留 172 款目录及来源，当前只对上述 19 款完成真实按钮适配，不把未适配目录显示成可用替换。后台大部分业务面板尚为索引项。编辑工作台以电脑为主要使用场景；「手机」是实际 390px 页面预览，不代表手机上的复杂编辑操作已经真人验收。

## 选择与动效替换（已生产）

- 默认选择模式。指针悬停显示对象，点击后右侧同步；嵌套组件可选层级。拖动有移动阈值，单击不生成无意义撤销记录。Escape 只取消选择，不穿透关闭业务弹窗。
- 左侧和效果清单共用定位，跨页面等待预览就绪再展开目标；保留清单背后的 iframe，并等待画布重新显示后再检查目标。定位前关闭无关的查词、菜单或背词弹窗，避免遮挡。连续选择以最后一次为准，主动点击或切回正常操作会停止尚未完成的自动定位。
- 学习设置、数据、确认弹窗，Menu 设置/生词本，阅读查词/导入/原位编辑等状态会自动打开。不能出现的源代码记录仍明确说明能力边界。
- 编辑预览直接呈现首页，重播页面可看原开场；正式首页的入场不变。
- 新增「阅读站的胶囊按钮」组件，沿用 PillNavAction 的底部圆弧填充和双层文字切换，300ms 进入、200ms 退出。可在个人库重播、拖动时间轴、换材质及颜色。
- 组件替换会停用并清理原胶囊 GSAP，隐藏原装饰层；保留真实业务元素、标签、事件、禁用状态。恢复原样/对比原版/撤销时重建原动效。仅换材质不强制关闭原动效。
- 编辑器的基础按钮样式不覆盖组件小样。文字变化与 React 内容替换会同步，移除文字色覆盖时恢复材质默认对比色。

## 方案与预览边界

草稿和发布版本存在服务器，刷新/换设备后仍可读取。并发窗口使用版本号冲突保护，不静默覆盖；冲突时可导出本地方案，再载入最新版本。发布只使用已保存草稿，不接收随发布附带的新样式。新页面采用已发布方案；已打开页面通过轮询同步，通常 15–20 秒以内，并非瞬间改变所有窗口。

预览使用真正的页面组件和隔离的学习样例，学习数据、答题、生成、扣额度、领取奖励和本机存储均不进入真实业务数据。后台部分已审查 GET 只读真实数据，其余操作不提交。预览中的学习进度和词典解释是样例，不作为 FSRS 或模型生成质量验证。退出工作台回到实际业务页后才恢复正常业务操作。

没有方案时不改变原站外观。原站用户的夜间设置、内容、算法、账户与收费边界保持。设计故障使用最近的已发布方案或原样，不能挡住阅读入口。编辑器本身不套用用户发布的样式，避免无法重新打开和恢复。

## 后续 agent 接入规则

- 先查看个人偏好与真实反馈。不要把本轮工作台的颜色和布局当作用户已确认的审美标准；最终视觉接受仍由用户决定。
- 持续维护 `lib/ui-inventory.json` 的中文名称、状态、来源、触发方式及能力；`lib/ui-targets.json` 是公开运行时精简版。新增目标先使用稳定的 `data-ui-target`，旧 CSS Module 前缀目标改名时须迁移已存方案。
- `uiDesignRegistry.ts` 管哪些参数/样式可用；不要接受客户端自带选择器、任意 CSS、HTML、脚本或远程代码。
- 新组件需逐项证明：挂载与移除后业务事件保持，文字/禁用状态更新正常，材质和全局/局部覆盖撤销完整，重复挂载无残留，键盘及减少动态效果可用。不得把复杂手势/物理节点的 transform 用通用位移覆盖。
- 方案使用 `account_settings.ui_design_v1`，`mutate_ui_design_v1` 在同一事务内处理版本、草稿、发布、回退和审计。只有服务角色执行；外部接口仍需服务器验证开发者账号。
- SDK 来自私有 `galio111/galio-design-library` 的 `7cd7c1c`，偏好文档已同步至 `cb00895`。`public/galio` 保存运行时、目录和来源许可；React Bits 的附加许可不得移除。当前是版本化静态适配，不在生产动态读取本机 3208 或执行私人远程脚本。
