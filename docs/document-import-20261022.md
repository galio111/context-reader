## Behavior

Text PDFs and Word `.docx` can be imported from the real article panel. Live login is required; accepted imports save to My Articles and use normal protocol-2 sync. The private original is served only to its owner. PDF pages preserve columns, typography, figures and equations; Word preserves document layout as supported by browser rendering. Source editing is disabled; original download remains available. No OCR was enabled.

In imported files only, single clicks do nothing; double-click selects a whole word and dragging expands partial word boundaries. Up to five lexical words use the existing contextual explanation pipeline; longer selections and non-lexical text (e.g. figure labels) use translation only. Punctuation-only selections are ignored. PDF selection geometry is calibrated from actual canvas glyph positions, including embedded-font mappings and word spacing. Scoped overlay highlights use the same range as the submitted text. Ordinary pasted/URL article interactions are unchanged. Source PDF pages, including images, vectors and stored annotation appearances, are rendered directly; transparent text adds selection. The authenticated owner-scoped proxy streams originals and supports ranges. The viewer loads original bytes, PDF runtime and worker in parallel; a separate account-scoped IndexedDB cache retains at most 40 MB of originals, so reopening avoids another original download. Import also seeds this cache. Cache failures silently fall back to the private route. Failed original loads expose an explicit original retry, never a replacement plain-text article. Fit width and actual 100% (96 CSS pixels per inch) are separate controls.

Full translation starts on explicit action, preserves original pages and stable saved block IDs, labels PDF page boundaries and caches translated blocks. Academic body selection excludes repeated page furniture, front matter and reference/back matter. Captions have a separate optional scope; the sidebar defaults to Chinese reading with optional source comparison and page jumps. For this paper: 51 body blocks, 6 captions, 127 excluded; historical 184-block caches remain stored and unchanged blocks replay without a new provider request. The supplied 11-page paper extracts approximately 51k characters / 184 blocks, within the complete-context budget. Longer documents use bounded target-centred context with opening definitions; every target remains translatable.

Body and caption jobs share the full selected reading context in original order, but translate and charge only their chosen targets. Switching scopes does not cancel existing jobs.

## Limits

20 MB per source, 150 PDF pages, 300k extracted characters. Scans/insufficient text, encrypted PDFs, old `.doc`, macro/embedded-object DOCX are not supported. Body/caption classification uses conservative heuristics and can require refinement for other layouts; it never removes anything from the original pages. PDF extraction follows content-stream order with geometric line grouping; irregular/untagged documents can need a better source export. DOCX complex layout, fonts and pagination can differ from Microsoft Word; export to PDF for the strongest fidelity. Uncached original files need a network connection; only the matching local account can reuse cached originals. Browser device emulation does not replace physical phone/Safari or user's final visual acceptance. Article deletion currently retains private source bytes conservatively for shared/recoverable references.
