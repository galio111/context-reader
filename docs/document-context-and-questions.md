One `preferences` object per immutable turn uses `document-question:v1:<encoded document id>:<encoded turn id>` and `{documentId, turn}`. The current authenticated owner is transport authority; the payload contains no owner identity. Same-account devices merge independent turns without whole-conversation replacement. Server CAS, cursor/bootstrap, manifests and private user-data storage remain unchanged. A cloud turn is committed to the owner-scoped IndexedDB transaction before advancing the sync manifest; cloud tombstones remove only that exact turn. Existing local-only rows upload on every full sync until acknowledged, including full runs with an older dirty-kind list. Opening another account never uploads the previous owner's records. Successful local saves notify preferences sync; cloud replay emits a local history event that refreshes already-open panels without regeneration or marking another edit. No new service or schema migration is needed. A one-time owner-bound protocol-2 snapshot replay recovers question objects that older clients may have acknowledged without projecting locally; it does not clear existing histories.
