# Imported document context and research follow-up

Status: deployed as 20261026T200500 (parent 20261026T193500, source 5d718fd5af8148449afc26333aff35ca05d69386); final live scientific-answer and complete-translation checks are in progress. The cumulative release preserves the parent account-switching work.

Imported PDF/Word selection resolves the sentence containing the selected occurrence, instead of sending an entire paragraph and truncating its beginning. The exact sentence is also the explanation-cache identity, so previously generated paragraph-context mistakes are not replayed for the corrected sentence. Unlabelled abstracts are included in body translation; first-page Received/Accepted and affiliations do not terminate the paper. Journal page furniture and fragmented numeric tables are excluded, while captions remain a separate explicit scope. Source files, stored blocks and article identities are unchanged. Document translation sends one target block per request, with bounded paper context, retaining completed output.

Both short lookup and passage translation have a collapsible “继续问 AI” section. Questions can concern the entire paper, terminology, methods, findings or language. Follow-up history keeps the last four turns; changing selection, document or account resets the local conversation and aborts the prior request. Answers receive the relevant body/caption blocks, opening context and conclusions within 60,000 characters / 230 blocks, not only the selected sentence. This is bounded document context, not an exhaustive long-document vector index.

Optional external reference lookup sends only the explicitly displayed search keyword to Wikipedia and Europe PMC, with bounded DNS-pinned reads and an 8-second deadline. It displays returned source links and distinguishes retrieved abstracts from paper evidence and general background. It adds no paid search service. Unavailable/empty searches are explicitly labelled and do not prevent a document-only answer. Private paper text and conversation history are never included in external search requests; they remain part of the existing authenticated AI answering request.

Validation before release: real gggg Polyphenol-mediated chitin source, exact ethanol and PMS sentence assertions, all-page body target coverage, native PDF reading, continuous questions and passage entry in isolated Edge; 167 architecture/document checks. External source retrieval separately verified on the current server, with Europe PMC results when Wikipedia is unreachable.
