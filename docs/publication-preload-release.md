# 首页外刊预加载与展开性能

## 当前状态

候选已实现，生产发布待核对。本轮起点是生产 20261002T225700（source ae4ece526668fa14bc1636445821f98291e500ae），累计合入 20261002T232000 后，再合入现行生产 20261002T233200（source 38bba496bf233a2d4f6cac0a16b74a3ee1336ec4）。未把共享脏根目录打包。

## 目标与实现

用户要求游客主推和三行精选尽早完整显示，登录前或“显示更多”展开前静默准备其余几百张封面，并减少进入外刊区域及展开列表的停顿。保留高清图、原构图、DPR、出现/离开/再次进入、悬停 3D、开屏与 Reader 转场。没有新增加载提示。

- 根路由为默认主推和三行共十张封面发出服务端预加载提示，普通精选封面也直接存在于 SSR HTML；原图原有响应式变体保持。
- coverSources.ts 用同一份 CSS 几何描述服务端、后台队列和实际图片，覆盖桌面三列、窄屏两列、主推、106% 图片和 111.112% 动效表面及宽图 object-fit 裁剪。移除每张封面的 ResizeObserver、布局测量和第二次状态更新。
- 首批下载完成后，游客和会员都可静默读取公开的轻量目录并预取全库封面。游客卡片范围和权限不扩大；登录后复用同一目录请求/结果。会员在工作台期间补齐目录，减少滚到外刊区才集中更新。
- 网络总并发桌面四个、触屏两个；后台最多占两个/一个，留出可见图片名额；解码最多两个，保留最多 24 个解码图对象和 1600 个就绪记录，其余复用浏览器 HTTP 缓存。按 URL、srcset、sizes、视口及 DPR 合并请求；隐藏标签页暂停新后台下载，离开首页释放订阅。
- 可见图片优先级用 IntersectionObserver 提供的坐标及滚动偏移计算，不在请求完成或每帧循环读取全部卡片布局。
- “显示更多”保留完整可搜索目录，按每批 36 张分拆 DOM 提交；原卡片动效继续绑定每批真实文章 ID。Reader 返回时优先挂载目标位置所需文章。
- 首批封面完成前，延后演示视频和 CET 的推测性预取；明确点击真题仍走原入口，不更改开屏时长。

## 诊断与证据

生产初始浏览器记录显示，部分普通封面到导航后约 4.3 秒才发出请求；停留后展开推荐 500 篇，最初只有 10 张就绪，490 张待加载，同时出现约 152 ms 和 187 ms 的长任务。旧队列只处理靠近视口且已经挂载的卡片，不会为折叠库存持续下载。

本地使用实际公开的 955 条目录、当前首页编辑顺序和本地账号状态夹具，按生产构建检查加载与展示。夹具不代表真实认证、同步或计费验收。

第一轮实现实测：十张图片约 0.21 秒一起开始请求；会员停留约 64 秒时后台有 222 个封面资源记录。展开后首批新增图片已就绪；全部 500 张分 36 张一批在约 1.36 秒挂载完成，六秒样本无超过 50 ms 的主线程长任务、无可见缺图。帧间隔 p95 约 12 ms，最大约 96 ms，不能将“无长任务”等同于完全没有丢帧。

冷缓存、80 ms 延迟、约 3 Mbps、2.4 千像素/秒的早期跳滑复测，在调整推测性资源优先级后仍记录到约 66 ms 的可见缺图；覆盖层下未完成图片另计，不当作用户看见的灰图。服务端预加载提示加入后的最终结果见本轮证据。没有以 HTTP 200、缓存字段或自动测试冒充全部图片体验通过。

## 验证与开放范围

累计当前生产后的最终构建通过。89 项核心回归、9 项媒体、7 项加载、13 项听力/播放器/跨供应商计费回归和九项发布契约、静态数据库读取审计通过。强制 DeepSeek Flash 503 后独立 Zhipu glm-4.5-air 接管、仅一次用量预留和成功结算通过。

服务端 preload 后的一次 3 Mbps/80 ms/禁用缓存及 SW 快速滑动样本：10 张封面于导航后 243–244 ms 发起，1.893–2.898 s 完成，样本内没有可见缺图；帧间隔 p95 12.2 ms，但最大 515 ms，故此样本不能证明无卡顿。更苛刻的会员冷启动在导航约 1.64 s 自动直达底部并展开，仍出现约 5.8 s 可见缺图区间，另有 66 ms 长任务。预热后展开的改善不能外推成冷网立即展开已经完成。

真实 Chrome 检查了桌面及 390×844、DPR 3 的日夜布局，手机无横向溢出，七张可见精选封面完整；减少动态效果下图片仍可见。普通封面离屏复位实际矩阵为 0.90，再入在 0/130/260/390/700 ms 取样为 0.90/0.90/0.977/0.995/1.00；悬停实测图片层 matrix3d 与旋转变量变化，保留 3D。公开生产阅读和运行验收在切换后追加。

待验收：用户原设备体验、真实手机和 Edge、极端冷网快速直达时全程零灰图，以及完整动效逐帧矩阵。保留这些边界，不能描述为所有网络和任意速度下均瞬时显示。
