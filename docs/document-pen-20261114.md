# PDF / Word 画笔

状态：独立分支实现，待生产接受。

PDF/Word 原文工具栏增加画笔开关和撤销划线。开启画笔时复用现有鼠标/触摸/键盘选区通道，但拦截查词回调，在选中文字下画红色下划线；关闭后恢复查词。标记按账号/文档保存在本机学习数据库，以页内归一化坐标覆盖呈现，缩放和重渲染后重画，不修改原件或文章块。此版不进行标记云同步，也不把标记写入下载原件。

已验证：14 项标记/选区回归、90 项核心回归。真实浏览器入口不可用，仅有 MCP Apps；桌面/手机双主题实机视觉、跨缩放实际坐标和用户操作验收未完成。构建/保护契约/生产身份与服务检查待完成。标记渲染只追加无指针事件覆盖层，不参与正文提取、翻译、问答、Admin 发布或缓存回放。
