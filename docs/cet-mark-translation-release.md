# CET 暂停划记与题目翻译

## 行为

- 暂停时可新增、改色、删除自测划记，计时仍暂停，作答与辅助仍按原规则限制；提交后划记固定。
- 在正文右侧空白松开、端点越出正文或拖动手机选区手柄，仍按可划记片段读取选区。菜单靠可见选区末端并限制在视口内。
- 修正纯文本渲染丢失最后分段终点的问题，整句选到末尾的划线不再漏画。
- 下划线宽度 2.5px、下移 .24em，开启避让字母下伸部，正文行距保持原值。
- 当前篇全文翻译包括正文、题干、选项及选词词库；历史题目和词库优先使用冻结快照。文章保存仍只含正文，翻译继续由点击启动并复用已有缓存/分批请求。

## 验证

95 项 CET、89 项核心回归、9 项发布保护契约通过。新增覆盖暂停增删改色、计时不变、提交只读、越界选区裁剪、视口限制及题目/历史翻译范围。生产构建通过；独立 `tsc --noEmit` 仍有三个原有听力测试类型错误（DOMWindow 参数及两个 mjs 声明），本轮改动未新增错误。

真实 Chrome 桌面：暂停跨两段拖至右边缘，菜单出现，整段句尾标记可见；计时保持 00:07。390×844：整句四行选择，菜单 left=8、right=262，页面无横向溢出。窄屏改色后提交成功，划记进入结果索引。浏览器模拟宽度不能替代物理手机长按/选区手柄验证。
