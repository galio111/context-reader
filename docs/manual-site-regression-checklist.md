# Context Reader 定期人工测试清单

这份清单供站长定期检查真实网站，不替代自动测试。建议每次记录日期、生产 `releaseId`、设备、浏览器、账号和截图/录屏链接；发现问题时先保留现场，再到 Admin 查看是否真的生成了错误记录。

## 建议频率与准备

- 每周快速巡检：桌面 Chrome + 一台真实手机，约 20–30 分钟，完成标有“每周”的项目。
- 每月完整巡检：桌面 Chrome/Edge、Android Chrome 或系统浏览器、iPhone Safari（可获得时），约 60–90 分钟，完成全文。
- 每次发布后：检查 `/api/connectivity` 的 `backendMode=mainland_internal`、`releaseId` 与预期一致，再测试本次受影响模块及“发布后必测”。
- 准备一个游客窗口、一个普通账号、一个 active Admin 账号；准备一篇有图精选、一篇无图精选、一篇带已发布译文的精选、一篇粘贴文章和一个可导入网址。
- 额度类测试前记录 Admin 中的已用次数，动作后刷新核对增量；缓存、输入失败、未完成前及时取消及未形成完整上游响应的故障应按规则不扣，DeepSeek 已完成但结果不完整的单独词典请求保持扣费。

## 发布后必测（约 10 分钟）

- [ ] 根首页 200；`/home-v2?test=1` 308 到 `/?test=1`；页面没有控制台 error。
- [ ] 游客能打开一篇精选，Reader 正文、来源、原文发布日期和首图正常。
- [ ] 划一个单词得到完整解释；立刻划另一个词，前一次被取消，界面不卡住且 Admin 不新增取消类错误。
- [ ] 单独查词得到完整词典；关闭再打开后状态正常。
- [ ] 手机 Menu 可打开“导入文章”；生词本可点进词条详情并返回列表。
- [ ] 打开再关闭 Menu，正文和翻译栏的左右位置不跳动。
- [ ] 公网 `/api/connectivity` 返回预期新 `releaseId` / `parentReleaseId`；Admin session、公开文章接口、健康、备份、回滚镜像按发布清单通过。

## 首页与精选外刊

- [ ] 每周：首次进入“推荐”时，主推和所有可见卡片都有一次完整图片/文字浮入；没有某几张静止、突然出现或只剩中间一张有动效。
- [ ] 切换时事、科技、文化、商业，再切回推荐；每次新文章卡都重新正确入场。
- [ ] 设置和清除阅读偏好各测一次；文章顺序变化但数量相同时，换入的每一张卡仍有动效。
- [ ] 桌面折叠态为主推 + 最多三行；主推后的三行不出现无首页图片文章。手机折叠态同样不拿无图文章补空位。
- [ ] 展开全部文章后，无图文章出现在较后位置并与有图文章穿插；不是集中占据首页，也不是被永久隐藏。
- [ ] 卡片标题再长也不截断按钮、不盖住下一张卡，图片动效判定不受标题高度影响。
- [ ] 阅读时长使用约 120 词/分钟并向上取整，短文至少显示 2 分钟；抽查 600 词约 5 分钟。
- [ ] 推荐卡悬停/触摸、分类切换、展开/收起和点击进入 Reader 均无横向滚动或布局跳动；开启“减少动态效果”时内容仍可见可点。

## Admin 候选与推荐编排

- [ ] 候选/精选列表显示原文发布日期；没有来源日期时写“发布日期未知”，不拿抓取或入库日期冒充。
- [ ] 列表和文章设置明确显示“有图/无图”；无图提示仅 Admin 可见，普通用户看不到内部标记。
- [ ] 取消“加入推荐候选池”后刷新首页，该文章不再出现在推荐栏；清除偏好、换设备/无痕窗口后也不能被兜底补回。
- [ ] 勾选“推荐主推”会自动保证其在推荐池；取消推荐池会同时取消推荐主推，但不会勾上“本栏主推”。
- [ ] 单独勾选或取消“本栏主推”只影响当前分类第一篇，不连带推荐池和推荐主推；刷新 Admin 后状态一致。
- [ ] 推荐池为空时推荐栏保持为空，不从全部已发布文章偷偷补回；分类未设人工主推时仍按分类正常展示。
- [ ] 有阅读偏好时推荐池内部按偏好重排；无偏好时明确的推荐主推在首位。
- [ ] 点击“上传全文翻译”后，按钮附近立即显示“正在上传”，完成后明确显示已上传、已经上传、没有完整译文或失败原因。

## Reader、查词与词典

- [ ] 每周：桌面单击一个词、选择 2–8 词短语、手机横向选择/长按，解释对象和选区一致。
- [ ] 解释流逐字段出现，完成后布局不突变；加入生词、复制、发音和重新生成可用。
- [ ] 在第一个解释未完成时立即选择另一个词：旧请求安静取消、额度退回、不出现错误邮件或 Admin 失败记录。
- [ ] 同一账号同一“词/短语 + 原句”再次查询命中缓存、不调用模型；另一台已完成同步的设备也能命中。游客仅当前浏览器有普通本地缓存。
- [ ] 断网后已缓存解释仍可打开；未缓存查询明确说需联网，不把账号显示成游客或退出。
- [ ] 单独查词测试英文原形、词形变化、短语、中文反查、拼写错误和 `fell` 一词多词头；结果完整且可滚动。
- [ ] 词典生成到一半主动关闭：及时取消不扣额度、不记 provider failure；若 DeepSeek 已完成调用但只给半截，提示重新查询、照常扣一次并记失败执行，warning 不发邮件。
- [ ] HTML 实体正文抽查：`T&amp;uuml;bingen` 等来源应显示为 `Tübingen`，不能在 Reader 中看到 `&uuml;`。

## 全文翻译、摘要与保存

- [ ] 打开/切换翻译工具不会自动开始；只有点击翻译区后才启动。
- [ ] 翻译逐段出现，已完成段落即时保留；关闭 Menu、词典、移动端底栏后翻译列不横移。
- [ ] 精选外刊已有 Admin 全文译文时，首次点击仍扣用户全文翻译额度，但 DeepSeek 执行数和模型成本不增加；再次查看完整缓存免费。
- [ ] 保存普通导入文章：先保存正文，再生成摘要并扣摘要额度；摘要失败时正文仍已保存。
- [ ] 保存带有效中文摘要的精选外刊：扣一次摘要套餐额度，直接复用精选摘要，DeepSeek 摘要执行数不增加。
- [ ] 保存后按钮固定为“已保存”，不存在“重写摘要/重新生成摘要”。
- [ ] 粘贴正文或 URL 导入后，从工具栏返回首页会询问是否先保存；浏览器返回键也会提醒未保存。
- [ ] 选择保存但未登录时停留在 Reader 并打开登录；取消保存才直接返回。

## 手机 Menu、生词本与导入

- [ ] 每周：Reader 和首页 Menu 的“导入文章”都能关闭 Menu 后打开真实导入层，不需要点第二次。
- [ ] Reader 内生词本列表上下滚动不会误开词条；轻触词条必定打开详情，返回按钮回到原列表。
- [ ] 首页 Menu 生词本执行相同测试；两处详情内容、删除、复制和来源跳转一致。
- [ ] 所有返回、关闭、主要操作命中区至少 44px；不被拖动把手、透明层或底部工具栏遮挡。
- [ ] 390px 宽度下 Reader 顶栏、Admin Reader 顶栏和底部工具条标签完整可见，无横向溢出。

## 导入、来源与日期

- [ ] 粘贴导入和 URL 导入分别测试成功、无正文、超时、断网和额度耗尽；失败保留输入并给可行动提示。
- [ ] URL 导入后的来源链接、作者、原文发布日期与来源页面一致；抓取日期只可作为内部诊断，不显示成发布日期。
- [ ] 图片成功本地化时正常显示；失败时是平静的来源说明/纯文本退化，不出现浏览器破图图标。
- [ ] 导入文章编辑后保存，空段、标题、列表、表格和整块删除图片均保持。

## 账号、同步、额度与离线

- [ ] 游客四个上海自然日池彼此独立：文章查词 10、单独查词 5、粘贴 2、URL 2（若 Admin 改过，以当前配置为准）。
- [ ] 缓存命中、输入校验失败、未发出上游调用的网络失败和及时取消不扣；DeepSeek 已实际消耗 token 的请求即使结果不完整也扣一次，同 action id 重放不重复扣。
- [ ] 登录前的本地文章/生词不丢；登录后跨设备同步文章、生词、解释缓存、翻译缓存与阅读位置。
- [ ] 模拟会话检查失败时显示明确有限离线模式，说明哪些本地内容可用；不伪装成游客或退出。
- [ ] 普通账号看不到 Admin 入口，直接请求 `/api/admin/*` 被拒绝；active Admin 正常。

## 错误中心、邮件与运维

- [ ] 用户输入错误、离线、网络失败、主动取消不进入 Admin 错误中心，也不发邮件。
- [ ] provider 半截流等可恢复 warning 可在需要时留诊断，但 `emailStatus` 为 suppressed；真正 error/critical 才进入邮件链。
- [ ] 同一错误 15 分钟内聚合计数，不重复轰炸邮件；错误卡的接口、代码、版本、首次/最近时间真实。
- [ ] 标记解决、删除和筛选可用；邮件正文不包含私人文章全文。
- [ ] 每月核对最近备份、隔离恢复、当前与直接父 release 镜像、磁盘阈值、健康检查和回滚入口。
