用户在 20261013T190024 上确认发音恢复，但每换一个单词都要点两次，第一次等待也不会发声。前版把预备好的录音交给原生播放器，冷录音仍走 Web Audio；恢复/解码失败只保存录音并提示再次点击。这不能满足首次点击的目标。原设备未采集日志，因此不宣称确定了唯一 Safari 底层原因。
