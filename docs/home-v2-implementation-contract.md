# Context Reader `/home-v2` 实现契约

这份文件是书本空间首页的当前唯一实现基准。后来的明确决定覆盖早期决定。若聊天上下文被压缩，先读本文件，再修改首页。

## 1. 产品目标

- 第一眼先让用户感受到网站的美感，随后立即理解语境查词与语境翻译的价值。
- 首页是一本文字与工具都真实可用的数字英语书，不是把多个普通网页区块套上纸张背景。
- 首页可以有较强的表达力，正式 `ReaderView` 必须安静。进入阅读器后移除主页鼠标字母和翻页场景。
- `/home-v2` 继续复用真实账号、用量、保存文章、公开推荐、URL 导入、解释和 `ReaderView`。不得制作脱离真实流程的假按钮或静态替身。
- `/home-v2` 是当前正式主页和首页实现的唯一来源；`/` 自动跳转到 `/home-v2`。所有返回主页、退出后返回、PWA 启动和离线页首页入口都必须落到 `/home-v2`。

## 2. 当前状态顺序

### 状态 0：闭合封面

- 初始显示一本完整闭合、有纸芯厚度、封面厚度、书脊和接触阴影的书。
- 从闭合封面首帧开始就存在完整页面滚动轨道与滚动条，不允许开书后才突然增加页面高度。
- 封面可由用户点击或向下滚动打开；滚动位置直接控制封面姿态，不使用计时器锁住开书或合书。任意中间帧向上滚动都必须从当前画面精确倒放，向下滚动则继续正放。
- 正面只在正面可见；封面背面使用无文字的数字纸张，禁止出现镜像标题。
- 封面品牌只显示放大的 `Context Reader` 与较小的“语境翻译魔法书”。产品界面不再使用 `CR` 方块标。
- 保留冷白、浅灰、淡蓝色调。封面样式可以继续评审，但不得退回扁平卡片。
- 封面彩色小球在没有鼠标输入时也要持续缓慢自由漂浮；鼠标进入封面后只是在原有漂浮上施加交互影响，离开后自然恢复，不得停成静态背景。
- 桌面封面必须有最小宽度，窄桌面优先保持书本比例，不允许被压成失真的细长矩形。
- 打开过程必须清楚可见，包含封面绕书脊翻开、纸芯显露、接触阴影转移、镜头轻微靠近和书本展开，不用普通淡入淡出代替。前封面是固定半书宽的硬板，翻动中只允许铰链轴平移和整板旋转，不得通过拉伸封面宽度伪造从单面到双面的展开；背板和纸芯各自从闭合位置平移到右半页，硬板外缘要保留可见厚度。

### 状态 1：开发者的话

- 封面打开后的第一幅展开页，左页暂时保持空白数字纸张。右页在封面完全落定前不显示任何寄语文字；落定后继续保留约 `280ms` 的纯空白停顿，再让大标题按字形从行内裁切区依次翻起并变清晰，正文按语义段落连续揭开，签名最后落定。该揭幕只属于从闭合封面进入前言的首次开封事件：从开始阅读页或推荐页向前翻回前言时，完整文字必须在目标纸张生成快照前就处于印刷完成态，随弯曲纸面一起出现，落定后不得再次补渲染或重播揭幕。反向合书会取消尚未开始的首次揭幕，完整合上再打开时才重新播放。
- 寄语是可直接替换的真实页面内容，不用营销式占位卡片；修改文字不得改变书页结构。

### 状态 2：开始阅读

- 左页负责真实微型文章体验：点击单词、横向选择短语、正式解释面板、一次性提示。
- 右页默认打开独立深度查词，同时保留“粘贴文章”和“输入网址”两个同页 Tab，不另建导入章节。
- 有最近阅读历史时显示“继续阅读”，游客或从未打开过文章的新用户不显示。
- “粘贴文章”“输入网址”“单独查词”是右页的三个同级入口。“单独查词”直接在右页内部显示可滚动词典，不再把整本书切换成独立词典界面。
- 独立查词以逐行结构化事件直接生成最终 UI：读音、义项、用法、搭配、词族、近义词、易错点和记忆提示按块出现，结束时不得换成另一套布局或另一份内容；切换粘贴、网址与查词 Tab 不卸载词典。查询词、最近结果和有界缓存只保留在当前浏览器标签页，并与文章阅读页右栏的“单独查词”共用，刷新可恢复，关闭标签页后清除。
- `CurvedPageTurn` 制作翻页快照时必须复制当前页全部表单值和嵌套滚动面的实时 `scrollTop` / `scrollLeft`；查词页或推荐页已经滚动到哪里，折叠纸面就必须从相同位置开始，不能跳回顶部或旧状态。
- 独立查词结果可加入生词本。折叠态显示英文、音标/词性与合并中文义项，不显示空原句或空翻译；展开后把用法拆成逐点独立行，并把搭配、例句、近义词辨析、词族、易错点与记忆提示分别作为独立语义区块，旧版已保存的合并字符串也必须兼容解析。该来源导入 Anki 时使用英译中卡：正面只放英文；背面完整展示中文义项、原形/词性/音标、美音与英音 TTS、用法分点、搭配、近义词辨析、词族、例句、易错点与记忆提示。
- 首页不提供图片上传。
- 粘贴文章和输入网址继续使用真实导入流程。

### 状态 3：推荐目录

- 推荐目录仍在同一本书中，不另起一个独立网页区块。
- 推荐目录必须继续显示与前言和开始阅读页一致的中央书脊、左右纸张层次与接触阴影，不允许变回一张无装订线的全屏面板。
- 推荐标题右侧显示轻量“每日更新”标识，并提供“个性化推荐”按钮。
- 点击“个性化推荐”打开阶段、阅读强度和兴趣弹窗；保存后立即刷新当前推荐排序，之后仍可修改。
- 未设置个性化推荐时，默认从四级、六级、考研、雅思和托福等四级以上公开库存中按日稳定换序；库存不足时再回退到全部有封面的公开文章。
- 有阅读记录后，后续版本应先自动推测用户适合的阶段并允许手动修改；当前版本不得伪造已经完成的阅读画像。
- 同屏显示多篇等权文章，封面更小，不能出现左边一篇远大于右边的失衡布局。
- 推荐封面必须存在；若候选文章没有封面，Admin 明确提示补图并禁止发布。正文内图片可有可无，有则保留。
- 卡片使用封面、标题和摘要。点击封面、标题、摘要或卡片空白区都视为打开该文章。
- 推荐目录读取服务端预载的真实公开文章；空库存时显示可理解的真实空状态，不伪造文章。
- 推荐目录标题只使用“推荐文章”，不显示再次按阶段筛选的一整行按钮，也不显示解释图片与标题点击关系的教学文案。

### 状态 4：进入 ReaderView

- 点击推荐文章后，以该文章封面为视觉起点。封面向视口中心放大，发生轻微深度/径向展开，随后连续变成文章页。
- 点击粘贴、URL、继续阅读或示例文章时，也使用相同的“当前书页铺满视口、装订线淡出”转场语言。
- 进入真实 `ReaderView` 后立即卸载书本场景和桌面鼠标字母。
- Reader 背景保留冷白数字纸张的安静气质，不增加持续跟随或翻页干扰。

## 3. 连续动效原则

- 桌面主页只存在一个持续书本场景。书的位置、透视、厚度、页影和装订线连续变化，不在章节之间重新生成四块页面。
- 页面采用原生自由滚动。滚动进度驱动局部 sticky 书页转场；书页内部有可滚动内容时先滚动当前页。桌面右页触底或推荐页触顶后，连续同向滚轮/触控板惯性必须继续被当前页吸收；只有停止约 `520ms` 后的下一次同向输入才能进入相邻章节。无内部滚动范围的页不制造额外等待。`760px` 及以下手机端只使用正常单列竖向滚动和离散章节边界，不执行逐帧书页 seek、自动收尾或滚动关联阴影。
- 翻页只表达真实状态变化：打开或合上封面、进入开发者前言、开始阅读、推荐目录、打开文章。右页内部切换词典/粘贴/网址 Tab 不翻整本书。
- 内页弯曲同样由滚动进度逐帧控制；正向滚到一半再反向时，纸张曲率、正反面、遮挡与接触阴影都沿原轨迹还原，不能等待上一段动画播完。任何封面或内页一旦进入翻动区间，滚轮、触摸或滚动键停下约 `90ms` 后都沿最后方向自动收完当前这一张纸；剩余收尾最长约 `480ms`。自动段仍必须使用柔软纸张密度、正弦页角抬升和可见曲面溢出，完整展示中段弯曲、纸背和移动接触阴影，不能用激进缓动把它压成硬板位移。新的正向或反向输入必须立即取消自动收尾，并从当前帧重新接管。
- 点击目录时只生成一张“当前页 → 目标页”的纸。即使跨过中间章节，也只视觉翻动一次，同时把滚动位置定位到目标章节，禁止排队补播中间页。点击封面或目录的关键翻页使用同一套可打断滚动时间轴，单次最长约 `620ms`，不依赖浏览器不可控的原生平滑滚动时长。
- 纸页翻动至少包含页角抬起、弯曲感、纸张背面、遮挡关系和接触阴影迁移。单独的 `rotateY` 不算完成。
- 竖向切片依次旋转的“栅栏式翻页”明确不接受。已选定 B 混合路线：自定义 3D 书壳持续保留封面、封底、书脊与左右纸芯；MIT `page-flip` 只负责一整张 DOM 快照纸的连续弯曲与遮挡，Wawa R3F 只作为运动和纸堆光影参考，不复制其源码。
- 翻页前同时保留当前与目标 React 展开页；视觉层克隆两者并在纸张遮挡期间交接真实活动页，不能淡黑、闪白或突然替换 UI。桌面 761–1280 px 的展开书最小宽度为 1160 px，居中并允许两侧对称轻微裁边，禁止压窄书本比例。
- 桌面鼠标字母是用户已经确认喜欢的品牌效果，必须保留原主页可见强度并显示在闭合封面、展开书页、按钮、输入区、Menu 与弹层之上，不能藏在不透明书本下面；只在当前可见的文章正文和解释阅读区域使用遮罩避让，隐藏或非活动展开页中的 `data-pointer-mask` 不得参与画布擦除，尤其不能遮掉前言空白左页的字母。进入 `ReaderView` 后卸载。输入框、文本框和可编辑区域必须保留正常可见的原生选词。
- 手机端只使用轻微触点涟漪。手机为单页竖向书，不缩小保留双页书；不挂载 WebGL 环境字母、`CurvedPageTurn` 快照或滚动关联 3D 动效，封面用静态彩色纸点保留品牌质感。章节通过离散状态直接切换，避免滚动时持续重绘。
- `prefers-reduced-motion` 下取消 3D 编排，使用短交叉淡变或直接切换，并保证全部功能仍可操作。
- 默认无声音。声音仅作为项目收尾阶段的可选优化提出。

### 纸面弯曲与页面交接的不可破坏约束

- `CurvedPageTurn` 的职责是把当前展开页和目标展开页克隆成一整张不可交互的 DOM 快照纸；真实 React 页面始终留在下方。`page-flip` 只计算这张快照纸的连续曲面、正反面和遮挡，不拥有章节状态。
- 快照页必须使用 `data-density="soft"`。折角从下方进入，垂直抬升维持 `sin(progress × π) × 页面高度 × 0.075` 的中段峰值；纸张接触阴影随 `--turn-progress` 横跨书脊迁移。不得把它改成 `hard`、单纯 `rotateY`、线性横移或会跳过中段曲率的激进缓动。
- 翻页层和 `page-flip` 引擎在视觉隐藏时仍必须保持可测量：父层可用 `opacity` / `visibility` 隐藏，但 `.engine` 必须保持 `display: block !important`，引擎、父容器、包裹层和块级层都保持 `position: absolute; inset: 0; width: 100%; height: 100%`。否则 React 同帧调用 `seek` 时会量到 `0×0`，纸张原点会变成半个书宽和半个书高的负值，翻页内容便跳到视口左上角。
- 曲面翻出页面边界是纸张弯曲的一部分。翻页层、引擎和 page-flip 包裹层必须保持 `overflow: visible`，并保留约 `2600px` 的透视；不得重新加入 `overflow: hidden`、`contain: paint` 或其他裁切绘制层，否则纸张会被削平或截断。真正的纸面内容仍由 `.turnPaper` 自身裁切。
- 端点判定需要同时容忍浏览器滚动像素取整和 page-flip 的端点清理。`CurvedPageTurn` 只在 `0.00001 < progress < 0.99999` 时绘制临时纸页；`BookHome` 使用约 `0.0015` 的章节边界容差决定已落定页面。不得把两者合并成严格相等判断。
- 翻页完成时必须先提交目标章节并关闭 turning 状态，再在下一帧调用 `pageTurnRef.clear()`。新一轮正向或反向输入必须取消尚未执行的清理帧。禁止在目标真实页提交前同步清空快照纸，否则会出现“翻完闪一下，又露出上一页”的回弹。
- 滚动时间轴仍是唯一姿态来源。空闲收尾只改变滚动位置：约 `90ms` 无输入后，以 `180–480ms` 的柔和正弦缓动走到相邻端点；点击封面或目录使用约 `260–620ms` 的可打断时间轴。任何新输入必须从当前曲率继续，不得另起一套不可逆动画。
- 修改 `BookHome.tsx`、`CurvedPageTurn.tsx`、`CurvedPageTurn.module.css` 或书本尺寸样式后，必须至少回归：第一张纸正向、第一张纸反向、第二张纸正向、翻到一半反向再正向、跨页目录直达。每次落定后只能有一个真实展开页可见，`seeking=false`、`turnActive=false`，不能闪回旧页，也不能把纸张定位到左上角。

## 4. 响应式与尺寸基准

- 1440×900 和 1920×1080 下，书本应占据主要视野，不显空，也不能用过大字体填空。
- 桌面双页内容优先使用空间和信息密度，而不是夸张标题。正文字号以长期可读为准。
- 手机端开书后先显示单页开发者寄语；开始阅读章节再分为微型体验页和查词/导入页，不把双页内容压入一个视口。
- 390×844 为最低移动验收尺寸，必须无横向溢出、无被裁切主动作、无无法滚动的书内内容。
- `/home-v2` 使用右侧 Staggered Menu。关闭状态保留既有 Menu 按钮；打开时彩色底板、主面板和菜单项依次进入。选项严格按“使用说明、生词本、保存文章、账号与用量、意见反馈”排列，只有开发者账号追加“admin后台”；不显示其他入口。除“admin后台”外，全部条目都通过桌面悬停、键盘聚焦或触屏点击在左侧原位展开，不得再跳到其他页面；“admin后台”保持开发者页面跳转。触摸指针不得触发任何悬停预览或悬停详情切换，手机只认明确点击；预览内提供“返回菜单”，生词详情内优先提供“返回生词列表”。只要没有切换到另一个菜单目标或关闭 Menu，桌面预览必须在鼠标移入并操作其内容时继续存在。桌面生词本、保存文章和意见反馈的预览上沿与对应菜单行上沿对齐，不得因内容数量改变或居中定位而裁掉上端；使用说明和账号与用量的完整页面预览从视口顶部延伸到底部，保留少量安全留白，形成近全屏阅读区域。左侧内容直接叠在保留可见、轻度模糊的首页背景上，不使用包住全部内容的重边框大卡片；长内容使用局部滚动。“使用说明”和“账号与用量”复用各自完整页面主体而不是摘要，保留原有目录、详细内容、按钮和独立滚动；使用说明中的阅读按钮直达首页粘贴文章工作台。“意见反馈”使用更宽的预览，直接提交私有反馈，并允许附加最多三张图片。Menu 底部始终显示账号昵称，未登录时显示“未登录”。
- “生词本”不再通过点击打开独立弹层：左侧预览展示全量、可检索的虚拟列表，检索使用一次建立的有序前缀索引，不能在每次按键时线性扫描全部词条。继续悬停具体词条时在更左侧展示完整学习信息、发音与可用的原句定位；列表滚动期间必须冻结悬停切换并禁用词条指针命中，避免固定鼠标下方经过的每条词反复刷新详情。紧凑列表使用固定虚拟行且不挂载逐行 ResizeObserver，文章内旧生词本继续使用真实动态测高。保存文章预览保持按最近打开排序并可上下滚动。Menu 锁定底层页面滚动，但菜单面板及所有预览滚动面自身可滚动。Menu 不提供退出登录，退出入口仍只放在 `/account/usage`。
- 顶部不铺设横贯屏幕的栏，只保留悬浮的 `Context Reader`、开始阅读与 Menu 三个动作块。

## 5. 推荐内容与 Admin 边界

- 手动候选支持粘贴文章和 URL，两种方式同级。
- URL 候选自动判断难度、国内学习阶段、考试路线、兴趣主题、阅读时长和时效性。
- URL 导入尽量提取推荐封面候选和正文图片。推荐封面必需，正文图片可选。
- 系统抓取不只追逐最新文章，优先补齐质量、难度和兴趣库存；永不自动发布，必须经过 Admin 审核。
- 游客和新用户应在推荐上线评审前拥有覆盖多个层级和兴趣方向的初始文章库存。

## 6. 评审与上线边界

- 每次用户可见代码修改后运行 `npm.cmd run build`，再部署到固定地址 `https://context-reader-ten.vercel.app`。
- 评审必须覆盖闭合封面、滚轮正反向开合、开发者寄语、桌面开始阅读双页、手机前言与阅读子页、右页内嵌词典、个性化推荐弹窗、带书脊推荐目录、文章入场、Menu 和 ReaderView 安静化。
- `/home-v2` 已是正式主页，`/` 必须继续跳转到它；后续评审直接在固定生产地址验证。
